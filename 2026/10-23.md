## 【arXiv 精选】

> 批次：cs.AI / cs.CL 当日新提交（Thu, 22 Oct 2026，ID 段 2610.29xxx–30xxx），聚焦 Agent / 工具调用 / 记忆 / 推理控制。

- [MemoryTax: The Bitter Lesson of Agent Memory](https://arxiv.org/abs/2610.29823) — 实证「记忆是弱模型的补丁」：Mem0/Zep 仅在 GPT-4o-mini 上胜过全上下文，而 Pi + Claude Opus 5.5 以不到一半成本拿到 99% 准确率，登顶成本-精度前沿。
- [Uni-Mem: Learning a Long-Horizon Agentic Memory Manager](https://arxiv.org/abs/2610.29671) — 用统一在线 RL 同时学习记忆的构建与检索，提出 Stage-Decoupled GRPO 与事件级信用分配（ECA），LoCoMo/LongMemEval 超此前最强 RL 记忆。
- [Remembering Through Change: Provenance-Preserving Hypergraph Memory](https://arxiv.org/abs/2610.29995) — MHG-Mem：多模态超图记忆联合组织实体身份、状态演化与视觉证据溯源，跨会话追踪实体变化，较最强基线提升 8.2–10.0%。
- [PerMIT: Securing Persistent Memory for LLM Agents](https://arxiv.org/abs/2610.28987) — 用 Lean 4 机器可检的完整性定理约束持久记忆：环境派生价值必须经「闸门确认」才能影响敏感动作，攻击面收敛为单一可审计决策，信任可随社区积累共扩展。
- [Steering Black-Box LLM Agents with Pitfall Anticipation World Model](https://arxiv.org/abs/2610.29139) — PAWM：不逐步预测观测，只在预判到陷阱时选择性介入，把即将到来的失败告诉黑盒 agent，ScienceWorld +24.3%、WebArena-Lite +7.7%。
- [Robust Soft Skill Adaptation via Behavioral Localization in Tool-Using Agents](https://arxiv.org/abs/2610.30041) — 发现文本技能的作用高度集中于少量轨迹位置：前 10% 位置贡献 96% 正向收益，据此用短 soft prompt 做选择性监督，替代冗长技能描述。
- [From Prompts to Posteriors: Can LLM Agents Perform Bayesian Inference in Context?](https://arxiv.org/abs/2610.29331) — LLM 上下文内更新信念普遍违反贝叶斯规则，但配备推理与代码执行后大幅改善，可逼近解析上难解的后验。
- [Memory-Centric Continual Learning for AI Agents](https://arxiv.org/abs/2610.29357) — MCCL：记忆的价值应以「是否改进未来行动」而非「能否检索到」来衡量，给出基底/资产/策略三轴分类、双循环生命周期与记忆缩放律框架。
- [Recursive Self-Improvement on a Budget: Scoring Code Edits Before They Run](https://arxiv.org/abs/2610.29121) — 用父代胜率+diff 特征的线性读数在代码编辑运行前预打分，配合 Huxley-Gödel Machine 选择，HumanEval+ held-out 87.0% vs 父代 81.2%。
