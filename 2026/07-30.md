## 【Hugging Face 每日精选】

**模型**
- [moonshotai/Kimi-K3](https://huggingface.co/moonshotai/Kimi-K3) — 开源 MoE 旗舰持续霸榜（99.2k 喜欢），社区热度不减。
- [baidu/Unlimited-OCR](https://huggingface.co/baidu/Unlimited-OCR) — 百度全栈开源 OCR，累计 2.69M 下载，支持 CPU / 消费级显卡本地部署。
- [tencent/Hy-Embodied-VLM-1.0](https://huggingface.co/tencent/Hy-Embodied-VLM-1.0) — 腾讯具身 VLM，MoE 每 token 仅激活 ~3B，强调物理世界 agent 推理与长程自适应。

**Spaces**
- [webml-community/bonsai-webgpu-kernels](https://huggingface.co/spaces/webml-community/bonsai-webgpu-kernels) — 浏览器 WebGPU 本地跑 1-bit 27B LLM，前端端侧推理新标杆。
- [pliny-the-prompter/obliteratus](https://huggingface.co/spaces/pliny-the-prompter/obliteratus) — 一键"模型解放" + 聊天 playground，带 Agents 标签的体验型空间。

**Datasets**
- [HuggingFaceCode/stack-v3-train](https://huggingface.co/datasets/HuggingFaceCode/stack-v3-train) — The Stack v3 训练集发布：4.9T tokens / 1.73 亿仓库 / 713 语言，源码内联可直接训练。
- [openbmb/UltraX-Preview](https://huggingface.co/datasets/openbmb/UltraX-Preview) — 函数调用式预训练数据精炼框架 + 5 个 20B-token 语料，登顶 Datasets Trending。

**论文（Daily Papers 07-29 批次）**
- [Parallel Decoding Distillation for Fast Image and Video Generation](https://huggingface.co/papers/2607.26004) — 并行解码蒸馏实现图像/视频快速生成（881 赞）。
- [Mage-VL: An Efficient Codec-Native Streaming Multimodal Foundation Model](https://huggingface.co/papers/2607.24904) — 高效的编解码器原生流式多模态基础模型（850 赞）。
- [ReDesign: Recovering Editable Design Structures from Images via Agentic Decomposition](https://huggingface.co/papers/2607.25565) — 通过 agentic 分解从图片恢复可编辑设计结构，前端 / AIGC 强相关。

## 【前端 → AI Agent 转型方向】

**框架**
- [Vercel AI SDK — Agent 抽象](https://sdk.vercel.ai/docs/ai-sdk/agents) — 新增原生 Agent 抽象（Agent 类 / 工具循环执行），继续坐稳 JS 生态推理层标准（周下载 2000 万+）。
- [Mastra](https://mastra.ai) — TypeScript 原生全栈框架（agent / memory / workflows / evals / observability 一体），1.0 已生产可用，被 Replit、PayPal、Adobe 采用。
- [LangGraph.js](https://langchain-ai.github.io/langgraphjs/) — 图式编排，显式节点 / 边 / checkpointer，适合需长程持久化、human-in-the-loop 的企业级工作流。
- [Claude Agent SDK](https://docs.anthropic.com/en/docs/claude-agent-sdk) — Anthropic 官方 agent SDK（原 Claude Code SDK），内置文件 / bash / 编辑 / computer-use 工具，深度 MCP 集成。

**学习资源**
- [The TypeScript AI Agent Stack in Mid-2026](https://developersdigest.tech/blog/typescript-ai-agent-stack-2026) — Mastra vs Vercel AI SDK vs OpenAI Agents SDK vs LangGraph.js 的对比与选型指南，含决策表与项目类型建议。

**研究 / 实践案例**
- [A New Role for Relevance: Guiding Corpus Interaction in Agentic Search](https://huggingface.co/papers/2607.24223) — 重新审视"相关性"在 agentic 搜索中引导语料交互的作用（83 赞）。
- [Keep It InMind: Benchmarking the Implicit-Association Blind Spot in Agent Memory](https://huggingface.co/papers/2607.24368) — 基准测试 agent 记忆中的内隐联想盲点，对构建可靠 agent 记忆层有参考价值（25 赞）。
