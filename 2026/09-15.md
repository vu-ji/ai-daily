## 【arXiv 精选】

### cs.AI（Agent / 工具 / 记忆 / 推理控制）
- [Skill Issue: Lessons from Optimizing Repository SKILLs for Coding Agents](https://arxiv.org/abs/2609.12720) — 系统总结编码 Agent 的「仓库级 SKILL」优化经验，直接对接 Skill 化工具工程。
- [LifeFuse-Mem: Lifecycle-Aware State Fusion Against Temporary Overwriting for Long-Term Memory](https://arxiv.org/abs/2609.12436) — 面向长期记忆的「生命周期感知状态融合」，解决临时覆盖导致的记忆丢失，对接 local-first 记忆层。
- [Residual Vector-based Reconstruction as Long-Context Recall Regardless of Context Window Size](https://arxiv.org/abs/2609.12686) — 用残差向量重建实现「与上下文窗口无关的」长程回忆，缓解 KV 膨胀。
- [What Drives Recovery in Agentic Text-to-Cypher? LAST-CQ: An LLM Agent Self-Refinement Framework](https://arxiv.org/abs/2609.12746) — 文本→Cypher 的 Agent 自修正框架，给出「何时该自我修复」的触发机制。
- [SoK: Rethinking Jailbreaking in the Era of Agentic AI](https://arxiv.org/abs/2609.12413) — Agentic AI 时代的越狱攻防系统综述，覆盖工具调用链下的新型攻击面。
- [K-Bench: A Benchmark for LLM Unlearning in Agentic Deployments](https://arxiv.org/abs/2609.12808) — 首个面向「Agent 部署场景」的遗忘（unlearning）基准，关注已授权又被撤销的记忆。
- [Embodied-BenchForge: A Closed-Loop Agentic Workflow for Embodied Benchmark Construction](https://arxiv.org/abs/2609.13082) — 用闭环 Agent 工作流自动构造具身智能基准，降低评测数据生产成本。

### cs.CL（Agent / 记忆）
- [LifeMem: Enabling Lifelong Experience Reuse for LLM Agents](https://arxiv.org/abs/2609.12655) — LLM Agent 的「终身经验复用」记忆机制，让经验跨会话沉淀可重用。
- [CueMem: Cue-Guided Context Reconstruction for Long-Term Conversational Memory](https://arxiv.org/abs/2609.12354) — 用「线索」引导上下文重建的长期对话记忆，提升长程对话一致性。
