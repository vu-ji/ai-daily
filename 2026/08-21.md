## 【arXiv 精选】

> 来源：cs.AI / cs.CL 8/21 新提交，聚焦 Agent / 工具调用 / 记忆 / 推理控制。链接统一 `https://arxiv.org/abs/XXXX.XXXXX`，标题与 ID 已逐条核验。

- [MidTool: Mid-training Data Synthesis for Agentic Tool Use](https://arxiv.org/abs/2608.20314)（cs.AI）— 用真实工具 API、MCP skills、文档工作流合成中期训练语料，教模型识别工具可用性、组合调用、从不完整信息恢复，BFCL/tau2-Bench/MCP Universe 全面涨点。
- [Learning When to Think: Adaptive Reasoning for Test-Time Compute Allocation](https://arxiv.org/abs/2608.20256)（cs.AI）— 让模型自学家选 NoThink/Short/Long 三档推理（GRPO 内学，无独立 router），MATH500 持平但平均响应从 4796 压到 2811 token（-41%），与 TokenBudget 同源。
- [MemTrapBench: Benchmarking Cognitive Traps in LLM Memory Use](https://arxiv.org/abs/2608.20202)（cs.AI）— 指出「记忆认知陷阱」：忠实且相关的记忆反而会扭曲推理；所有记忆策略都跑输无记忆设定，给记忆层可靠性敲警钟。
- [SAPO: Single-Rollout Autoregressive Policy Optimization for Agentic RL](https://arxiv.org/abs/2608.19842)（cs.AI）— 单滚动自回归策略优化，策略与价值共享一个 backbone，缓解 Agentic RL 训练震荡，比 PPO/GRPO 稳定且省显存。
- [ReCache: Efficient KV Cache Reuse and Compression for Tool-Augmented LLM Agents](https://arxiv.org/abs/2608.19662)（cs.CL）— 资源级注意力把工具/skill schema 的 KV 块独立缓存，TTFT 加速 3.655×、KV 显存降 92.43%，直接砍掉 Agent 推理开销。
- [Remember, Verify, or Ask? Cross-Family Evaluation of Memory Commitment](https://arxiv.org/abs/2608.19564)（cs.CL）— 跨模型家族评估 Agent 记忆承诺行为（持久化/仅当前/重新验证/问用户），揭示「该问不问、错误持久化」的系统性偏差。
- [Inducing Task Models from Computer-Use Traces](https://arxiv.org/abs/2608.20319)（cs.CL）— 从计算机操作轨迹自动诱导任务模型（目标分解 + 控制流），技能复用让留出任务准确率 +30%，优化 Agent 工作流理解与回放。
- [Stopping and Routing LLM Judge Panels](https://arxiv.org/abs/2608.19802)（cs.CL）— 研究何时中止、如何路由多个 LLM 评判面板，给出可复用、可审计的评测调用计划，直接服务推理预算控制。
- [Thinkingbox: a Sandbox and Benchmark for Agents in Stateful Business Workflows](https://arxiv.org/abs/2608.19741)（cs.CL）— 微软出品，提供隔离 MCP 工具会话 + 终态校验；最强模型 pass@1 仅 65%、pass^20 仅 25%，强调「一次成功≠可靠」，贴近生产级验收。
- [ReguSim: Evaluating LLM Agent Rule Grounding in Financial Compliance](https://arxiv.org/abs/2608.19974)（cs.AI）— 把合规评估拆成「陈述推理/尝试动作/执行强制/监控证据」四要素，指出只看规则引用会误判，对应 Agent 合规护栏设计。

- [Best Agent Skills, MCP Servers & Prompts (2026)](https://aicoolies.com/categories/agent-skills-prompts) — MCP 工具/服务器生态地图：FastMCP、Langfuse 观测、Supermemory 记忆引擎、E2B 代码沙盒、CUA 桌面控制等，前端接 Agent「手」的现成清单。

## 今日值得深入

1. **[Learning When to Think (2608.20256)](https://arxiv.org/abs/2608.20256)** — 把「是否进入推理」做成可学习的自适应决策（NoThink/Short/Long 三档，GRPO 内学、无独立 router），token 砍 41% 还不掉点。这和你自己沉淀的 **TokenBudget**（预算内/外、trim）是同源思想：推理预算不该是写死的硬上限，而应是模型按难度自决。建议精读，对照 WorkMusic 的预算检查落地。
2. **[PolicyGuide (2608.19861)](https://huggingface.co/papers/2608.19861)** — 从「守卫单步动作」升级到「引导整体合规工作流」。正好对应你 **QA 严过关** persona 的验收哲学：别只拦截单点违规，要把合规内建进 Agent 工作流。建议结合云笺 CloudNotes 选 LangGraph 做 agent runtime 的设计来读。
