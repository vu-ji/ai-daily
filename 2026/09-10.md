## 【arXiv 精选】

> cs.AI / cs.CL 当日新提交中，与 Agent / 工具调用 / 记忆 / 推理控制最相关的条目（链接统一用 abs）。

- [Procedural Graphs: Self-Evolving Execution Structures for LLM Agents](https://arxiv.org/abs/2609.09153) — Google 提出可自我演进的程序化图执行结构，让 LLM Agent 动态重组执行流程。
- [ExecCritic: Learn to Test, Test to Improve for Coding Agents](https://arxiv.org/abs/2609.09133) — 让编码 Agent「先学测试、再借测试改进」，闭环提升代码质量。
- [MeClear: Risk-Aware Memory Clearance for Long-Horizon LLM Agents](https://arxiv.org/abs/2609.09115) — 用合作博弈归因做长程 Agent 的风险感知记忆清理，解决上下文膨胀。
- [Graph-Based Personalized Memory for LLM Agents: Representation, Evolution, Retrieval, and Evaluation](https://arxiv.org/abs/2609.08599) — 图结构建模个性化记忆的表示/演化/检索/评测全链路。
- [MemForest: Efficient Agent Memory Management via EventTree Partitioning and Progressive Merging](https://arxiv.org/abs/2609.08273) — 事件树分区 + 渐进合并的高效 Agent 记忆管理。
- [What Eviction Destroys: A Restore-Counterfactual Audit of Forgetting in Agent Memory](https://arxiv.org/abs/2609.08279) — 用「还原-反事实」审计 Agent 记忆驱逐带来的遗忘代价。
- [Revoked but Still Authoritative: An Empirical Study of Revocation Enforcement in Agent-Memory Systems](https://arxiv.org/abs/2609.08258) — 实证 Agent 记忆系统中「已撤销却仍生效」的权限失效问题（安全相关）。
- [ToolLoop: Closed-Loop Tool-Use Data Synthesis via Decomposed Generation and Dynamic Self-Feedback](https://arxiv.org/abs/2609.09072) — 分解生成 + 动态自反馈的闭环工具调用数据合成（EMNLP 2026）。
- [CreaMem: A Scene-Aware Memory Architecture for Personalized Agents](https://arxiv.org/abs/2609.08550) — 场景感知的个性化 Agent 记忆架构（EMNLP 2026 Findings）。
