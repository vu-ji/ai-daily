## 【arXiv 精选】

> 以下为 cs.AI / cs.CL 当日新提交中与 Agent / 工具调用 / 记忆 / 推理控制最相关的条目（链接统一为 abs 页）。

- [CHIME: Credit-Aware Hierarchical Memory Evolution for Long-Horizon Agentic Planning](https://arxiv.org/abs/2609.02074) — 信用感知的层级记忆进化，支撑长周期 Agent 规划，直击本地优先 Agent 的「记忆」短板。
- [Beyond Context Windows: Persistent Discovery Context for Data-Centric Agents](https://arxiv.org/abs/2609.02129) — 为数据中心 Agent 提供超越上下文窗口的持久发现上下文，类比 Agent 的「外置记忆库」。
- [ToolGate: An Executable Acceptance Pipeline for Tool-Dependent Scientific Benchmark Construction](https://arxiv.org/abs/2609.02067) — 可执行验收流水线，约束「依赖工具的基准」的合法性，缓解工具滥用与评测作弊。
- [Discriminative World Models for Web Agents](https://arxiv.org/abs/2609.02885) — 面向网页 Agent 的判别型世界模型，提升复杂 Web 环境下的决策与交互能力。
- [PGPO: Potential-Guided Policy Optimization for Multi-Turn Agentic Tasks](https://arxiv.org/abs/2609.02236) — 潜力引导策略优化，用于多轮 Agent 任务的强化学习训练。
- [Diagnosing with Insights: Structured Analysis of Agent Failures via Behavioral Abstractions](https://arxiv.org/abs/2609.02371) — 通过行为抽象对 Agent 失败做结构化诊断，给出可解释的故障洞察（可调试性）。
- [Language Models Can Control Their Own Attention](https://arxiv.org/abs/2609.02737) — 研究表明模型能自主控制注意力机制，开辟「推理过程可控」的新路径（推理控制）。
- [Trace as State: Reasoning Traces as Conditional States for Long-Context Transformers](https://arxiv.org/abs/2609.02702) — 将推理轨迹作为条件状态注入长上下文 Transformer，提升长上下文推理（推理 + 长上下文）。
- [Efficient GUI Agents: A Systems Survey of Observation, Memory, Action, and Runtime Optimization](https://arxiv.org/abs/2609.02309) — 系统综述 GUI Agent 在观察、记忆、行动与运行优化上的效率方法（Agent + 记忆）。

## 今日值得深入

1. **Agent 记忆机制（[CHIME](https://arxiv.org/abs/2609.02074) + [Beyond Context Windows](https://arxiv.org/abs/2609.02129)）** — 一个做「信用感知的层级记忆进化」支撑长周期规划，一个做「超越上下文窗口的持久发现上下文」。两者合起来正好是本地优先 Agent（你的 Loomry / CloudNotes）最缺的「记忆」主线：如何把跨会话上下文外置、如何对长任务做信用分配。值得对照你 StorageProvider / 记忆抽象的设计深挖。
2. **LangChain MCP 重构（[无状态 + elicitation via interrupt](https://www.langchain.com/blog/mcp-in-langchain-stateless-protocol-elicitation-and-more)）** — 新 MCP 规范把「工具中途向用户确认参数」做成可重试的 LangGraph interrupt，且工具列表可缓存、协议无状态可任意 redeploy。直接对应你 LangGraph runtime + tool elicitation（Human-in-the-loop）的设计，是工具调用工程化最该吸收的范式。
