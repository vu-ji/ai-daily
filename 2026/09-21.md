## 【arXiv 精选】

> 聚焦 Agent / 工具调用 / 记忆 / 推理控制，链接统一为 `arxiv.org/abs`（批次：09-18 Fri）。

- [SkillAA: Attribution-Guided Skill-Graph Updating with Targeted Validation and Rollback](https://arxiv.org/abs/2609.20455) — 归因引导的技能图更新，带定向验证与回滚，对 pi-agent 的 Skill 自进化架构（更新要有验证+回滚）直接有参考价值。
- [When AI Agents Commit: Cognitive Serializability Across Data, Evidence, Policy, and Authority](https://arxiv.org/abs/2609.20261) — 研究 Agent「提交/承诺」时的认知可串行化，横跨数据/证据/策略/权限，属于推理控制与多 Agent 协同。
- [UnifiedPlayers: Enhance Tool-Integrated Reasoning in Agentic Reinforcement Learning](https://arxiv.org/abs/2609.20089) — 在 agentic RL 中增强工具集成推理（tool-integrated reasoning），直接打工具调用与推理控制。
- [On-Demand Attention: Language Models Know When to Recall](https://arxiv.org/abs/2609.20734) — 证明 LM 能自主判断「何时召回记忆」，对接本地优先 Agent 的记忆检索时机与按需注意力。
- [Chronicle: Cut-Point Replay for Regression Testing of LLM Agents](https://arxiv.org/abs/2609.20625) — 用切点重放做 LLM Agent 的回归测试，提升长程 Agent 的可靠性与可调试性。
- [Language-model groups overstate consensus when replaying human deliberation](https://arxiv.org/abs/2609.20543) — 多智能体重放人类审议时会夸大共识，提醒多 Agent 协作中的群体偏差风险。
- [Not All AI Agents Are Equal: Characterizing Resource and Performance Dynamics](https://arxiv.org/abs/2609.19947) — 刻画不同 Agent 的资源消耗与性能动态差异，帮助选型与成本估算。
