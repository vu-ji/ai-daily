## 【Hugging Face 每日精选】

- [DeepSeek-V4.1-Flash](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash) — 趋势榜延续：552B MoE、MIT 许可、1M 上下文，主打 Engram 条件记忆，是 Agent 长程记忆方向的代表模型。
- [MiniCPM5-2B](https://huggingface.co/openbmb/MiniCPM5-2B) — openbmb 新一代 2B 端侧模型（1 天前更新），开放各训练阶段权重，适合本地 / 端侧 Agent 轻量落地。
- [Edge0-35B-A3B-preview](https://huggingface.co/Edge0/Edge0-35B-A3B-preview) — 35B MoE 预览版（4 天前更新），中等规模、高性价比推理选项。
- [SenseNova-U1.5](https://huggingface.co/papers) — Daily Papers：迈向「原生统一视觉智能」的多模态模型，图像 / 视频 / 语音统一建模。
- [NCP-ArchPreview Technical Report](https://huggingface.co/papers) — Daily Papers：用「下一概念预测（NCP）」把 LM 推向潜在空间架构，探索下一代语言模型范式。
- [An Open Recipe for IMO Gold](https://huggingface.co/papers) — NVIDIA 公开训练 Nemotron 拿下 IMO 金牌级数学推理的完整配方，推理训练可复现参考。
- [CIVOS: Emergence or Recitation?](https://huggingface.co/spaces) — HF Space（约 10 小时前）：探究 LLM Agent 是「真正发现」还是「背诵记忆」，直击记忆 / 推理真实性评估。
- [challenge-2026/challenge_data](https://huggingface.co/datasets/challenge-2026/challenge_data) — 开源真实机器人操作数据（500+ 小时 LeRobot 格式），具身 Agent 训练新养料。

## 【arXiv 精选】

- [Artificial Id: Drive and Persistent Alignment in Agentic AI](https://arxiv.org/abs/2609.11911) — 研究自主 Agent 的「驱动」机制与持久对齐，直击 Agentic AI 价值对齐难题。
- [MindTopo: Can Foundation Models Reason in Topological Space?](https://arxiv.org/abs/2609.11900) — 评估基础模型在拓扑空间推理的能力，推理控制新基准。
- [Negative Self-Distillation: Learning to Reason by Avoiding Flaws](https://arxiv.org/abs/2609.11699) — 通过规避自身缺陷做负向自蒸馏来提升推理，训练技巧可复用。
- [RouteRepair: Instance-Level Failure Diagnosis and Targeted Repair in LLM-Based Automated Heuristic Design](https://arxiv.org/abs/2609.11452) — 对 LLM 自动化启发式设计做实例级诊断与针对性修复，Agent 自纠错方向。
- [Agentic Share-of-Search: A Multi-Agent AI System for Competitive Decision-Making in LLM-Mediated E-Commerce](https://arxiv.org/abs/2609.11190) — 多智能体系统在 LLM 中介电商中的竞争决策，多 Agent 协作案例。
- [Overview of NLPCC 2026 Shared Task 11: Agent-Based Experiment Reproduction from Scientific Papers](https://arxiv.org/abs/2609.11117) — 基于 Agent 从论文自动复现实验的共享任务，Agent 科研自动化。
- [ProMediConv: Benchmarking Proactive Conversational Agents in Legal Dispute Mediation](https://arxiv.org/abs/2609.11101) — 法律调解场景主动式对话 Agent 基准，对话 Agent 评测。
- [Auto-RecSys: Harnessing Autonomous Research Agents for Industry-Scale Recommender System](https://arxiv.org/abs/2609.10922) — 用自主研究 Agent 构建工业级推荐系统，Agent 落地工业。
- [FlexComp: One Model for Every Ratio in Context Compression](https://arxiv.org/abs/2609.11149) — 单一模型覆盖任意比例的上下文压缩，缓解长上下文 / 记忆压力。
