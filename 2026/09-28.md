- [SAGE: Mitigating Long-Horizon Reasoning Biases via Topological Guidance](https://arxiv.org/abs/2609.30192) — 用拓扑引导缓解长程推理偏差，对推理过程做结构性纠偏。

- [PartHackBench: Certified Equal-Progress Stress Tests for Partial-Credit Tool-Agent Evaluation](https://arxiv.org/abs/2609.29578) — 面向部分信用（partial-credit）工具智能体的认证式压力测试基准，更公平地评测工具调用。
- [Stale Does Not Mean Unsafe: Guard Precision for Tool-Using LLM Agents under Infrastructure State Races](https://arxiv.org/abs/2609.29522) — 在基础设施状态竞争下保障工具调用 LLM agent 的守卫精度，陈旧状态≠不安全。
- [LLMersion: A Local-First AI Agent Framework for Low-Cost Home Language Learning](https://arxiv.org/abs/2609.29672) — 本地优先的 AI 智能体框架，低成本家庭语言学习，直接对标 local-first Agent 的「数据自持 + 离线可跑」诉求。
