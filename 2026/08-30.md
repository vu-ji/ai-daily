## 【arXiv 精选】

### 论文 / 研究亮点（cs.AI、cs.CL 当日新提交，聚焦 Agent / 工具调用 / 记忆 / 推理控制）
- [WikiSkill：把 Agent 经验编译成持久知识库做技能演化](https://arxiv.org/abs/2608.27454) — 分离原始经验/wiki/可执行技能三层，小模型带技能可超越大模型，跨模型族可迁移。
- [HarnessLens：行为感知验证的高效 Harness 演化](https://arxiv.org/abs/2608.27311) — 预算感知框架对候选改动按行为相关任务选择性验证，held-out 性能 +7.6~13.6% 且省评测预算。
- [SARA：当工具输出变成命令——分离动作诱导与执行授权](https://arxiv.org/abs/2608.27146) — 工具输出越权风险来自混淆动作诱导与执行授权，四点设置下 ASR 压到 ≤0.63% 且保持任务效用。
- [GraphMemix：查询感知证据森林做长程多模态 Agent 记忆](https://arxiv.org/abs/2608.26983) — 把记忆组织建模为查询相关证据森林，精度-生命周期成本建立新 Pareto 前沿。
- [面向可扩展可治理 Agentic 运行时的契约中心架构](https://arxiv.org/abs/2608.27086) — 提出 Skill/Harness/Scaffold + 栈外数据基座四责任对象与可证伪测量协议。
- [治理自治 Agent 的五个运行时原语](https://arxiv.org/abs/2608.26696) — discovery/identity/governance/attestation/supply-chain，行动生效前按策略中介、哈希链签名账本可第三方验证。
- [AgentJudgeBench：评测 LLM-judge 在 Agent 工具调用上的可靠性](https://arxiv.org/abs/2608.26623) — 3808 实例覆盖六类 DAG 拓扑，难任务无真值下六 judge 收敛 77–82% 天花板，结构化 rubric 最多 +6.5pp。
- [TTPO：测试时策略优化](https://arxiv.org/abs/2608.27448) — 无标签匹配有标签 OPSD，Qwen3-1.7B 在 TTT 下从 38.0% 升到 45.2%，关 thinking 再 +25~36pp。
- [CritICL：推理时用小模型失败模式做弱到强泛化](https://arxiv.org/abs/2608.27455) — 把失败模式当指引通过 critique 式 in-context 注入，少生成、低 token 成本媲美 test-time scaling。
- [INTENT-AS-A-TOOL：用「意图」工具细粒度追踪 Agent 错位](https://arxiv.org/abs/2608.27348) — 给模型专用意图表达通道，调用概率即无 judge 的细粒度倾向信号，定位在线干预关键步。
