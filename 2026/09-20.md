## 【arXiv 精选】

> 聚焦 Agent / 工具调用 / 记忆 / 推理控制，链接统一为 `arxiv.org/abs`。

- [An Empirical Study of Harness Design for Coding Agents](https://arxiv.org/abs/2609.20804) — 编码 Agent 的 harness（工具与执行框架）设计实证研究，给出提升代码智能体性能的实操结论。
- [RAFT: A Stateful Retrieval-Augmented Framework for Troubleshooting Agents](https://arxiv.org/abs/2609.20754) — 有状态 RAG 框架赋能排障 Agent，已录用于 EMNLP 2026 Industry Track。
- [SoL-Pi: Recursively Scaling Auto-Research Loops for Efficient Agent Harness](https://arxiv.org/abs/2609.20519) — 递归扩展自动化研究循环的 Agent harness，附 NVIDIA 开源代码与项目页。
- [How Do Agent Harnesses Create Value?](https://arxiv.org/abs/2609.20474) — 剖析有状态 LLM Agent 中「规划信息」与「发布控制」在 harness 里如何创造价值。
- [AgentPProf: Semantic Profiler for Long Horizon AI Agents](https://arxiv.org/abs/2609.20301) — 面向长程 Agent 的语义性能剖析器，定位长任务里的瓶颈步骤。
- [JustMem: Just-Enough Memory Access for Long-Term Conversations](https://arxiv.org/abs/2609.19877) — 长对话的「刚好够用」记忆访问策略，显著降低跨会话记忆开销。
- [PetriBench: Benchmarking LLM Reasoning over Dynamic State Spaces](https://arxiv.org/abs/2609.19883) — 在动态状态空间上评测 LLM 推理的基准，测推理而非背诵。
- [RetireOPD: Self-Retiring On-Policy Distillation for Agentic RL](https://arxiv.org/abs/2609.20784) — 用「自我退休」机制改进 agentic 强化学习中的 on-policy 蒸馏。
- [DeepSeek-V4.1-Flash: Pushing the Limits of KV Cache Compression](https://arxiv.org/abs/2609.19969) — 极致压缩 KV Cache 突破显存与上下文长度限制，提升长上下文推理效率。
