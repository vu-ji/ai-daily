### 论文

- [Metis: Memory Foundation Model](https://huggingface.co/papers/2607.26760) — 254 赞，把记忆做进模型骨干：持久化记忆状态 + memory-attention 读取，更新只需一次前向传播、无需梯度，推理时权重全冻结
- [Memory Decoder at Scale: A Pretrained, Parametric Long-Term Memory](https://huggingface.co/papers/2607.27919) — 另一条路线：离线训一个 6.9B 记忆模块与冻结基座混合预测，给 410M Pythia 挂上后 17 项基准均分从 29.86 提到 37.34
- [MemHarness: Memory Is Reconstructed, Not Replayed](https://huggingface.co/papers/2607.28272) — 上海 AI Lab 提出记忆是「重构」而非「回放」，直接挑战当前主流的检索式 Agent 记忆实现
- [Frontis-MA1: Training an AI4AI Model towards Recursive Self-Improvement in ML Engineering](https://huggingface.co/papers/2607.28568) — 162 赞，训练能在机器学习工程中递归自我改进的 AI4AI 模型，AutoML Agent 方向的新高度
- [Is Deep Research Reliable? Misleading Knowledge Induces False Conclusions](https://huggingface.co/papers/2607.20891) — 误导性知识如何让 Deep Research Agent 得出自信但错误的结论，做资讯型 / 检索型 Agent 必读的失败模式清单

### 社区讨论

## 今日值得深入

> 以下两条作为转型学习重点参考，建议精读。

1. **Agent 记忆的路线之争：[Metis 论文](https://huggingface.co/papers/2607.26760) + [dev.to 深度解读](https://dev.to/breachprotocol/metis-puts-an-agents-memory-inside-the-model-instead-of-in-a-database-beside-it-30lk)** — 同一周里出现了四种答案：Metis 把记忆压进模型骨干（前向传播更新、零梯度），Memory Decoder 外挂一个预训练参数化记忆模块，MemHarness 主张记忆应被重构而非回放，还有上周那篇文件系统记忆主张就用 Agent 自己维护的 markdown 文件。四条路线都还是几天前的预印本、都未被独立复现，但方向已经收敛到同一个问题上。对前端转型者的实际意义是：**你现在写的「向量库 + 检索塞 prompt」的记忆方案，是当下唯一可落地的工程解，但它大概率不是终局**。读懂这场争论，能让你在设计记忆层时预留好抽象边界，而不是把检索逻辑焊死在业务代码里。

2. **[Agentic UI Frontend Engineer Roadmap 2026](https://www.techinterview.net/blog/agentic-ui-frontend-engineer-roadmap) + [Vercel AI SDK React 实操指南](https://letsbuildsolutions.com/blog/web-engineering/building-ai-powered-user-interfaces-in-react-streaming-responses-tool-call-rendering-and-progressive-enhancement-with-the-vercel-ai-sdk)** — 前者给路线，后者给代码，是目前「10 年前端如何切进 Agent」最直接的一组材料。核心判断：前端的护城河不在于会调 LLM API，而在于**处理非确定性、慢响应、可中断的交互**——tool call 三态渲染、流式骨架屏、stop/reload 控制、AI 不可用时的降级，这些恰好是十年前端经验能直接复用且别人补不上的部分。建议今天就把 useChat + 一个真实 tool 的三态渲染跑通，这是最小可交付的转型证据。
