## 【arXiv 精选】

- [ProgRouter: Online Progress-Guided Orchestration for Multi-Agent LLM Workflows under Quality-Cost Tradeoffs](https://arxiv.org/abs/2608.25992) — EMNLP 2026：把多 Agent 工作流每一步的 LLM 选择建模为「进度增益 vs 时间/成本预算」的在线路由决策，降本同时保持任务质量（与 RouterClient / TokenBudget 同频）。
- [Tunable Tool-Call Rates in LLM Agents via Representation Steering](https://arxiv.org/abs/2608.25198) — 证明工具调用倾向可由残差流单一线性方向在推理时单调调节（调用率 0→90%，开放域 QA 0.29→0.56），给三级路由/工具开关提供白盒控制旋钮。
- [CaSKG: Counterfactual-Causal Skill Graphs for Scalable Agent Skill Retrieval](https://arxiv.org/abs/2608.25500) — 用反事实因果探针给技能图边赋置信度，恢复先决/状态变更/验证步骤，ALFWorld 成功率 80.0→86.8、ScienceWorld 72.6→80.5。
- [LivingRAG: Augmenting Graph RAG with Experience](https://arxiv.org/abs/2608.25960) — 给 Graph RAG 加「可写可复用推理经验」，验证过的经验回写图，复用先验时提精度并降补全 token。
- [Learning What to Share and What to Personalize: Hierarchical Strategy Co-Evolution for Agent Memory (HiPS)](https://arxiv.org/abs/2608.25329) — EMNLP 2026：把记忆管理拆成「全局共享基础 + 用户个性化层」，跨人物轨迹抽取共享策略、个性化 delta，策略与任务结果共进化。
- [Reconstructing the Right Episode: Evaluating Interleaved Conversational Memory Beyond Long Context (SCALE-QA / TSIM)](https://arxiv.org/abs/2608.25655) — EMNLP 2026：在扁平无分段长线程上评测「交错对话记忆重建」，TSIM 在 3 个后端上比最强基线高 5.6–17.6 点。
- [SwarmWorld: Stigmergic technological evolution in societies of language-model agents](https://arxiv.org/abs/2608.26081) — 无角色/无预设的 LM 智能体社会通过物理信息素自组织出更鲁棒的技术组合，超越 best-of-N 孤立搜索。
- [VISA: Agentic Self-Evolving Data Synthesis for Multimodal Instruction Following](https://arxiv.org/abs/2608.26013) — 把多模态指令合成重构成自演化 agent 循环，失败样本触发诊断恢复、验证信号写回记忆，MM-IFEval 持续提升。
- [JIT-Agent: Scaling Harness Intelligence via Just-in-Time Harness Evolution](https://arxiv.org/abs/2608.25593) —（同 HF 高赞）JIT harness 进化随任务在线扩展智能体能力边界。

## 今日值得深入

1. **ProgRouter + Tunable Tool-Call Rates — 路由与工具调用的「可计算控制」**
   - [ProgRouter](https://arxiv.org/abs/2608.25992) 把多 Agent 工作流每一步的 LLM 选择建模为「进度增益 vs 时间/成本预算」的在线决策（EMNLP 2026），与你的 RouterClient / TokenBudget 同一思路；[Tunable Tool-Call Rates](https://arxiv.org/abs/2608.25198) 进一步证明工具调用率可由残差流单一线性方向在推理时单调调节（0.29→0.56），等于给三级路由和「工具调用开关」一个白盒旋钮——可直接映射到 WorkMusic / 云笺 的 RouterClient 预算检查与 fail.jsonl 归因。
2. **CaSKG + LivingRAG + HiPS / SCALE-QA — 记忆不是堆上下文，而是「可校准、可复用、可个性化」的图/经验层**
   - [CaSKG](https://arxiv.org/abs/2608.25500) 用反事实因果给技能图边赋置信度（ALFWorld 80→86.8）、[LivingRAG](https://arxiv.org/abs/2608.25960) 把验证过的推理经验写回图可复用并省 token、[HiPS](https://arxiv.org/abs/2608.25329) 与 [SCALE-QA/TSIM](https://arxiv.org/abs/2608.25655) 分别解决「个性化策略共进化」与「长程交错对话记忆重建」——对云笺 RAG / 记忆层和 Agent 记忆评估是硬约束，建议作为记忆层重构的对照基线。
