## 【arXiv 精选】论文 / 研究亮点（cs.AI、cs.CL 当日新提交中与 Agent / 工具调用 / 记忆 / 推理控制最相关的条目）

- [An Empirical Study of Harness Design for Coding Agents](https://arxiv.org/abs/2609.20804) — 系统研究编码 Agent 的 harness 设计要素，直接对接 pi-agent 的 harness 结构取舍。
- [RAFT: A Stateful Retrieval-Augmented Framework for Troubleshooting Agents](https://arxiv.org/abs/2609.20754) — 面向排障 Agent 的有状态检索增强框架，记忆与检索显式解耦。
- [SoL-Pi: Recursively Scaling Auto-Research Loops for Efficient Agent Harness](https://arxiv.org/abs/2609.20519) — 递归式自动研究循环扩展 harness，形成闭环自改进。
- [How Do Agent Harnesses Create Value? Planning Information and Release Control in Stateful LLM Agents](https://arxiv.org/abs/2609.20474) — 有状态 LLM Agent 的规划信息与「发布控制」，把推理控制权上移为显式机制。
- [AgentPProf: Semantic Profiler for Long Horizon AI Agents](https://arxiv.org/abs/2609.20301) — 长周期 Agent 的语义性能分析器，观测记忆/状态随时间的演化瓶颈。
- [UnifiedPlayers: Enhance Tool-Integrated Reasoning in Agentic Reinforcement Learning](https://arxiv.org/abs/2609.20089) — 把工具集成推理作为 agentic RL 的训练信号，强化「调用工具→推理」闭环。
- [TRACE: Accountable Agentic Retrieval for Source Discovery in Digital Archives](https://arxiv.org/abs/2609.19897) — 可审计的 Agent 检索框架，保留来源溯源，契合记忆层可解释需求。
- [JustMem: Just-Enough Memory Access for Long-Term Conversations](https://arxiv.org/abs/2609.19877) — 长对话「刚好够用」的记忆访问策略，按需检索以降低开销并保持连续性。
- [F2DR: A Fine-Grained Full-Pipeline Reward Framework for DeepSearch Workflows](https://arxiv.org/abs/2609.19827) — 面向 DeepSearch 工作流的细粒度全链路奖励框架，强化多步检索/推理对齐。
