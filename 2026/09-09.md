## 【arXiv 精选】

**论文 / 研究亮点**（cs.AI、cs.CL 当日新提交中与 Agent / 工具调用 / 记忆 / 推理控制最相关的条目）

- [Does Your Agent's Memory Survive a Model Upgrade?](https://arxiv.org/abs/2609.05339) — 受控实验研究智能体记忆在底层模型升级时的「可移植性」，揭示记忆与 provider 强耦合的风险。
- [Multi-Step Tool-Calling over Korean Open Public APIs](https://arxiv.org/abs/2609.05395) — 面向公开 API 的多步工具调用基准 + 数据合成配方，已被 EMNLP 2026 产业轨道接收。
- [CUA-Universe: Hybrid GUI+CLI Agents 环境](https://arxiv.org/abs/2609.05374) — 可扩展、动态的混合 GUI+CLI 智能体运行环境，支持训练与评测。
- [Compact-Memory LLM Agents via Online Max-Member Clustering](https://arxiv.org/abs/2609.04915) — 在线最大成员聚类 + 原子感知打包，实现紧凑记忆的 LLM 智能体，降低长上下文成本。
- [TROVE: Adaptive Agent Skill Orchestration](https://arxiv.org/abs/2609.05019) — 通过轨迹验证与编辑实现自适应技能编排，优化任务执行路径。
- [Substrate-Aware AI Agents](https://arxiv.org/abs/2609.05232) — 将「执行上下文（substrate）」作为一等输入，构建感知底层运行环境的智能体架构。
- [RefactorPlatform: 仓库级重构 Agent 受控评测](https://arxiv.org/abs/2609.04898) — 开源 harness，对仓库级代码重构智能体做受控评估。
- [Beneath the Surface of Chains-of-Thought](https://arxiv.org/abs/2609.04753) — 从机制可解释性角度剖析 LLM 链式思维（CoT）中的推理操作。
- [Verifier-Guided Explainable Reasoning Framework](https://arxiv.org/abs/2609.05221) — 验证器引导的可解释推理框架，融合 Gold-Anchored QLoRA + 任务感知 MoE + 组相对 RLVR。
- 研究亮点（HF Daily Papers）：**Bilevel Coordinated Reflection** 证明文本-only 反射门存在结构性盲区，换用 grounded verifier（SRMA）把 SWE-bench 从 58.4% 提升到 72.2%；**τ²-Bench** 让 coding agent 构建可部署客服 agent，最强配置仅通过 23.9% 部署仿真（专家参考 82.2%）。
