## 【arXiv 精选】

> 以下为 cs.AI / cs.CL 当日新提交中与 Agent / 工具调用 / 记忆 / 推理控制最相关的条目（链接统一为 abs 页）。

- [CordisBench: Can Language Models Reason About Component Lifecycles in Dynamic Agent Harnesses?](https://arxiv.org/abs/2609.01600) — 评测语言模型在动态 Agent 框架中对「组件生命周期」的推理能力，直击 Agent runtime 的工程痛点。
- [AgentFactory: Towards Automated Agentic System Design and Optimization](https://arxiv.org/abs/2609.01045) — 迈向「自动化智能体系统设计 + 优化」的工厂化框架，研究如何让 LLM 自动搭建和改进 Agent 系统。
- [CoBRA: Learning Tool-Use Boundaries via Counterfactual Margins](https://arxiv.org/abs/2609.00967) — 通过反事实边界学习，让 Agent 知道「什么时候该用工具、用到什么限度」，缓解工具滥用。
- [Making Prospective Memory SLM-Shaped: Typed Intention Stores for Small-Model Agents](https://arxiv.org/abs/2609.01272) — 为小模型智能体设计「类型化意图存储」，实现前瞻记忆（Prospective Memory），本地/端侧 Agent 落地的关键机制。
- [EDGE: Error Dependency Graph-Guided Multi-Error Attribution in Multi-Agent LLM Systems](https://arxiv.org/abs/2609.01360) — 用错误依赖图指导多智能体系统中的「多错误归因」，提升多 Agent 系统的可调试性。
- [Explore Before Committing: Hypothesis-Guided Search for Deep Research Agents](https://arxiv.org/abs/2609.01294) — 深度研究智能体中「先假设、后提交」的引导式搜索策略，改善长任务探索效率。
- [One Policy, Any Budget: Internalizing Budget-Aware Search via Reinforcement Learning](https://arxiv.org/abs/2609.00813) — 用强化学习让单一策略内化「预算感知搜索」，对 token budget 控制（类比前端 performance budget）有直接借鉴。
- [Where the Verifier Fails: A Category-Level Audit of Reward Signals in RLVR](https://arxiv.org/abs/2609.01354) — 对 RLVR（基于验证器的强化学习）奖励信号做类别级审计，揭示验证器的系统性失败模式。
- [Polished but Unresolved: Identifying Late-Stage Pressure States in Long-Horizon Tool-Use Agents](https://arxiv.org/abs/2609.00823) — 识别长周期工具调用智能体在「任务后期看似完成实则未解决」的高压力状态，对 Agent 可靠性评测很有启发。
