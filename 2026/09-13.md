## 【Hugging Face 每日精选】

**模型**
- [DeepSeek-V4.1-Flash](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash) — 552B MoE、MIT 许可、1M 上下文、KV Cache 压到 890 字节/token，今日 HF 模型趋势榜首位（趋势分 1681），旧 v4-pro 接口 9/14 起切换至此模型。
- [MiniCPM5-2B](https://huggingface.co/openbmb/MiniCPM5-2B) — OpenBMB 面向本地助手/代码/工具调用的紧凑模型，131072 token 上下文，罕见地开放基础训练、中训、指令微调各阶段权重与数据（Apache-2.0）。
- [Spark-X2.5（4B / 1.7B）](https://huggingface.co/XHToken/Spark-X2.5-4B) — 支持 200+ 语言、最长 100 万 token 上下文（混合完整注意力 + 滑动窗口），Apache-2.0，主打本地长材料处理。
- [Tencent AuK（1.5B 语音）](https://arxiv.org/abs/2609.08936) — 腾讯混元开源 1.5B 语音生成+编辑基础模型，所有任务统一用自然语言指令表达（TTS/改写/音高/语速/情感/气息），已上架 HF。
- [NeoHorse-1](https://huggingface.co/papers) — TokenRhythm 首个「Agent-Native」模型，用 Routing Harness 把执行经验转成训练信号实现递归自进化，3 天 HF 下载 12,193，技术报告登 HF 每日论文榜首。

**开源项目 / 社区讨论**
- [HF 联创关注 4B 端侧开放权重 Agent](https://www.163.com/dy/article/L6MFCM3105561FZX.html) — 4B 参数 + 4bit 量化 + MLX 的本地智能体系统信号，反映 HF 对「端侧自主 Agent」方向的押注。
- [HF Blog：Agent 训练正从「堆模型」转向「堆环境」](https://huggingface.co/blog/sergiopaniego/rl-environments-2026) — 分析指出 Agent 缩放瓶颈已从模型规模转向执行环境/沙箱/验证器/rollout 基建，TRL、OpenEnv 等开源基建战略价值上升。
- [EvoSafeHarness](https://arxiv.org/abs/2609.05903) — 登 HF 当日论文榜首：论证护栏应是「按模型×领域×对手拟合」的工件而非通用配置，DecodingTrust-Agent 攻击成功率从 45.6% 降到 10%。

## 【arXiv 精选】

> 聚焦 Agent / 工具调用 / 记忆 / 推理控制（批次 Fri, 11 Sep 2026）

- [COBRA-Skills：上下文老虎机引导的 Agent 技能进化](https://arxiv.org/abs/2609.11682) — 用 contextual bandit 在线挑选并演化 Agent 技能，把「技能沉淀」做成可学习的优化回路。
- [MAPLE：记忆增强的语言+进化规划](https://arxiv.org/abs/2609.11636) — 记忆驱动的规划框架，Agent 用历史经验指导未来计划生成与迭代。
- [面向高扇出 Agent 沙箱的记忆压缩](https://arxiv.org/abs/2609.11294) — 针对一个 Agent 扇出成百上千子任务的沙箱场景，给出可行的上下文/记忆压缩方案（对接 MicroVM 隔离部署）。
- [When Agents Disagree：多 Agent 集体决策的贝叶斯反向推理](https://arxiv.org/abs/2609.11709) — 无标签锚点下用贝叶斯反向推理消解多 Agent 意见分歧，做集体决策。
- [Mr.LHDR：真实世界长程深度研究 Agent 基准](https://arxiv.org/abs/2609.11318) — 多模态、真实长程（long-horizon）深度研究 Agent 评测集，代码数据已开源。
- [Sci-MMR：多步证据支撑的科学推理（多模态 Agent）](https://arxiv.org/abs/2609.11243) — 评测 Agent 在多模态证据间做多步推理的能力，贴近真实科研助手场景。
- [Beyond Confidence：LLM 推理的稳定性感知测试时自适应](https://arxiv.org/abs/2609.11393) — 不靠置信度、靠稳定性做推理阶段的 test-time adaptation，提升鲁棒性。
- [SearchAtlas：用证据查询图分析 Agentic 搜索策略](https://arxiv.org/abs/2609.10901) — EMNLP 2026 Findings，将 Agent 搜索行为建模为可解释的证据查询图，便于诊断搜索策略。
- [Can LLMs Normalize Databases？多 Agent Schema 规范化框架](https://arxiv.org/abs/2609.11141) — 多 Agent 协作做数据库 schema 归一化，Benchmark + 框架一并给出。
- [Negative Self-Distillation：靠规避缺陷学习推理](https://arxiv.org/abs/2609.11699) — 在线自蒸馏新范式，让模型从「避免自身错误」中自我提升推理。

- [ProductHunt 2026 LLM 开发工具榜](https://www.producthunt.com/categories/llm-developer-tools) — LangChain 领跑多步 Agent/RAG，Ollama 本地推理居首，Mastra（TS 栈）、FastMCP 3.0、GraphBit（Rust-core Agent 框架）本月上新。
- [前端老兵 48 天 AI Agent 实战：从 TypeScript 到技能封装](https://kwkr.cn/news/357852) — 在职前端 Leader 用下班时间走通「Agent 搭建→工具调用→技能封装→业务落地」全链路，判断 2026 前端面试题已转向「会不会搭 Agent」。

- [自进化 Agent 路线：Hermes / Evolver](https://www.sohu.com/a/1075375445_99926552) — 从 Manus（闭源云端）到 OpenClaw（本地优先）到 Hermes（干完活自动沉淀技能），核心是「越用越聪明」的记忆+技能自进化循环。

## 今日值得深入

1. **记忆驱动规划（双视角）**：[MAPLE](https://arxiv.org/abs/2609.11636)（记忆增强规划）× HF 当日论文 [Memory as Plans](https://arxiv.org/abs/2609.11561)（机器人先用记忆整理成紧凑计划再执行）—— 一个偏「规划生成」、一个偏「执行调度」，正好拼出 local-first Agent（Loomry / CloudNotes）记忆层的两条主线：经验如何指导计划、长历史如何压缩成可执行计划而非反复读全量。
2. **护栏是「拟合工件」而非「通用配置」**：[EvoSafeHarness](https://arxiv.org/abs/2609.05903)（HF 当日榜首，按模型×领域×对手定制护栏）× [OpenAI Agents API](https://openai.com)（harness 作为托管服务）—— 直接挑战「一份安全配置通吃所有部署」的工程惯性，对接你本地 Agent 的 guardrail 设计姿态：护栏要按部署环境单独拟合、可验证、可度量效用损失。
