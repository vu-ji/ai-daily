## 【arXiv 精选】（cs.AI / cs.CL，10-23 批次）

- [Muffin: A Shared Memory Buffer for Asynchronous AI Agents](https://arxiv.org/abs/2610.31355) — 异步多智能体共享记忆协议：编排器按推理需求路由，私有推理保持本地、中间发现经共享 buffer 异步交换，20 个基准设置中 17 个最佳，精度 +19.2 点而 token 少用 77.4%。
- [The Value of Memory in Language Agents](https://arxiv.org/abs/2610.31303) — 决策论框架追踪记忆价值全链路（原始历史→持久状态→操作使用→恢复修订）："与答案零互信息的指针仍可降低精确恢复成本"，给出记忆分配与恢复选项保留的可测原则。
- [Memory-Aware Reward Modeling: Learning Human Preferences for LLM Memory Use](https://arxiv.org/abs/2610.31272) — 87 位用户约 1000 对真人判断：带记忆回复并不总被偏好，自动评估器也系统性高估记忆价值；新奖励模型偏好预测准确率 72.8%，呼吁把用户偏好纳入记忆优化目标。
- [When LLMs Forget What They Believe: Characterizing State Integrity Collapse in Long-Horizon Dialogues](https://arxiv.org/abs/2610.31314) — EMNLP 2026：定义"状态完整性崩塌"（记得约束却不再执行），88.6% 失败是行为漂移而非遗忘，50 轮深对话仍存在，结构化状态锚定可恢复 24.4 点。
- [Adaptive Skill Granularity for Coding Agents: Runtime Routing and Macro-to-Micro Recovery](https://arxiv.org/abs/2610.31461) — 把 Skill 粒度视为运行时动作抽象策略：特征控制器+有限状态恢复执行器，宏技能失败后 macro-to-micro 回退——"技能库应是可检索、可执行、可验证、可恢复的资源"。
- [Certified Execution Harness for Agentic AI: Safe and Least-Intrusive Petri-Net Supervisory Control Between Reasoning and Action](https://arxiv.org/abs/2610.31376) — 用 Petri 网监督控制把 LLM 与工具间的 harness 形式化：注入请求前置条件（能力/批准/预算）不满足即拒；重规划闭环中常规监督器可能任意侵扰，给出最小侵扰安全监督器刻画。
- [Learning What to Ask for Tomorrow: Active Preference Acquisition for Long-Term Personalized Web Agents](https://arxiv.org/abs/2610.31107) — 用"预期个性化价值"（未来任务累计效用−提问成本与披露风险）决定主动问什么：20 任务跨度下获取 80.3% 高价值缺失偏好（当前任务 VOI 仅 5.1%），27.6% 的问题拿回 84.2% 效用。
- [ReflectPO: Reflection-Guided Policy Optimization for Long-Horizon LLM Agents](https://arxiv.org/abs/2610.30933) — 反思引导 RL：用轨迹分支差异与重复访问构造错误恢复提示 + 树结构信用分配，两个长程工具基准平均最优，显著提升自偏差识别与错误恢复能力。
- [ColaBench: Evaluating Memory-Guided Knowledge Acquisition in Personal Agents](https://arxiv.org/abs/2610.30989) — 个人 Agent 记忆引导知识获取基准：349 任务/10 画像/13033 文档，Evidence Graph 串联个人条件-披露-证据链；MemKB 86.25% 准确率，多历史事实整合任务增益最大。
- [EpiSEM-Bench: Evaluating Safety and Evidence Recovery in LLM Agents under Missing Evidence](https://arxiv.org/abs/2610.31650) — 300 对匹配不安全/安全任务，系统抑制关键事实测"证据缺失下的不安全执行"：10 个模型抗遗漏能力差异巨大，恢复访问降低但不消除误执行。
