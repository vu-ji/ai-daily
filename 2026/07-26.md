## 今日值得深入

1. **[AREX：递归自我改进的深度研究 Agent](https://huggingface.co/papers/2607.21461)** — 本周最高赞论文，核心思路是 Agent 在研究循环中持续改进自身的工具与策略，是「自进化 Agent」方向的代表性工作。转型学习中值得精读其自改进回路设计，可类比前端「增量构建/HMR」的反馈闭环思维。

2. **[Vercel AI SDK 7 vs Mastra 1.0：TS 转 Agent 的两条路线](https://developersdigest.tech/blog/typescript-ai-agent-stack-2026)** — 前端工程师转 Agent 最现实的选择题：AI SDK 7 适合「在 Next.js 里加 AI 功能」（useChat + 流式 UI，20 行起步）；Mastra 1.0 适合「独立 Agent 服务」（自带内存、eval、MCP、Studio）。建议先用 AI SDK 7 跑通一个流式聊天，再用 Mastra 搭一个带工作流的独立服务，对比两者的心智模型。
