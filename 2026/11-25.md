## 【arXiv 精选】（cs.AI / cs.CL · 11-25 当日新提交）

- [Delegent: A Multi-Agent Harness That Reduces Cost without Sacrificing Performance](https://arxiv.org/abs/2611.33098) — 前沿模型只做决策，把查代码/跑测试等简单子任务委托给本地 27B SLM，长程 coding 成本降 67% 且不掉性能
- [ShellBench: What Matters More for AI Agents, Models, or Harness](https://arxiv.org/abs/2611.32946) — 5.3 万次 rollout 实证：模型选择比 harness 选择更影响成绩，但头部三模型只差 1.1 分，成本却差 6 倍
- [The Control-Flow Tax: Specialized Decision Routing for LLM Agent Workflows](https://arxiv.org/abs/2611.32365) — agent 控制流路由占总成本 42.5%，换专用 System-1 决策模型后成本降 49.6%、耗时降 33%
- [VISE: Verifier-Independent Skill Self-Evolution with Feedback from Tool Implementations](https://arxiv.org/abs/2611.32480) — 没有验证器也能自进化：从工具源码提取能力/用法/输出格式，反向修订 SKILL.md，成功率 +9~13 分
- [ExpGuard: Guarding Long-Horizon LLM Agents against Corrupted Experience](https://arxiv.org/abs/2611.32085) — 经验记忆也可能被投毒：检索时用异质图预测风险并在线修复，防止有害指令跨任务潜伏
- [Leto: Utility-Centric Agent Memory](https://arxiv.org/abs/2611.33005) — 记忆的价值在于提升未来回答而非忠于过去：索引保留原文，请求到达时重放补全上下文，用响应结果闭环优化记忆选择
- [SAG-Mem-1.0 Technical Report](https://arxiv.org/abs/2611.33124) — 零 LLM 构建成本的对话记忆：原文分块 + BM25 + 查询时词法扩展找互补证据，LoCoMo/LongMemEval 双榜第一
- [Bathys: Advancing Deep Search Agents](https://arxiv.org/abs/2611.32660) — 9B/27B 开源 deep search agent，BrowseComp 66.5%/80.5%，SFT+KTO+上下文压缩下的在线 RL 训练框架
- [SecondChance: Benchmarking Reliable Error Recovery in AI Agents](https://arxiv.org/abs/2611.31586) — 错误恢复基准：最强模型无人协助仅 16% 能恢复，且"改正错误"≠"完成任务"

## 今日值得深入

1. **[VISE（2611.32480）](https://arxiv.org/abs/2611.32480)** — "工具实现即反馈源"的思路可以直接搬进 pi-agent 的 Skill 工作流：不依赖任务验证器，靠对比工具源码与 SKILL.md 的差异来自动修订技能文档，是 Skill 自进化闭环里最便宜的一环。
2. **[SAG-Mem-1.0（2611.33124）](https://arxiv.org/abs/2611.33124) × [Leto（2611.33005）](https://arxiv.org/abs/2611.33005)** — 两篇记忆论文代表 local-first 记忆层的两条互补路线：SAG-Mem 证明"不提取、不总结、保留原文 + 查询时词法扩展"就能拿到 SOTA，Leto 则提醒记忆选择要以未来效用为准——正好对应我们本地记忆层"存什么"和"取什么"两个核心决策。
