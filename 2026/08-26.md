## 【arXiv 精选】论文 / 研究亮点（cs.AI、cs.CL 当日新提交，聚焦 Agent / 工具调用 / 记忆 / 推理控制）

- [Prime Agent: A Self-Improving RLM Harness](https://arxiv.org/abs/2608.23552) — 开源长程 harness：持久 IPython REPL + Continual Harness 跨轨迹保存记忆/技能/子 agent 规格，ARC-AGI-3 RHAE Best@1 从 30% 拉到 95.5%。
- [ReWorld: An Interactive World Model with Long-Horizon Memory](https://arxiv.org/abs/2608.23565) — 用少量全局注意力头 + 姿态索引 landmark bank 在固定预算下实现分钟级长程记忆召回，滑动窗口早把证据驱逐时仍能复现起点视图。
- [AgentWeave: Routing Before Reasoning for Efficient Function Calling](https://arxiv.org/abs/2608.23078) — 推理前先确定性路由缩减候选工具集：少暴露 70.18% 工具、省 61.70% 输入 token、本地延迟降 50.95%，直接对应「路由先于推理」的成本控制。
- [AutoSaddler: Automatic Harness Optimization with Durable Updates](https://arxiv.org/abs/2608.23041) — 把 harness 优化建模为离线学习，从执行失败信号迭代修补；GAIA2/SWE-Bench Pro/Terminal-Bench 2.0 分别 +9.0/+9.6/+10.0 pp。
- [SWE Refactor Bench: 编码 Agent 能否完成全仓库技术栈迁移？](https://arxiv.org/abs/2608.23564) — 20 个整库迁移基准，8 模型 520 次运行仅 5.4% 通过「迁移完整性+行为正确+agentic 验证」三关，最佳 claude-opus-5 仅 47/100。
- [Signal or Noise? Agent Skills 在 Web 开发中的基准研究](https://arxiv.org/abs/2608.23067) — 31 个公开 WebDev Skill 实测：注入目标技能使 Pass@2 降 1.3–4.2%、token 成本增 72–394%，仅 17–36% 的 skill-项目对受益；呼吁按部署路由 + 长度匹配对照。
- [Meta-Moderator: 用元认知赋能多 Agent 辩论](https://arxiv.org/abs/2608.23029) — 把辩论 moderation 当成可学习的元认知过程（独立训练、EMNLP 2026 Findings），跨 5 基准优于常用决策层并可迁移。

## 今日值得深入

1. **AgentWeave + AutoSaddler + Prime Agent（工具路由与 harness 自动优化）** — 三条同日论文把「Agent 可靠性」从模型能力拆到系统层：先路由缩减候选工具集（省 token、提函数调用准确率），再把 harness 当成可离线学习/持久更新的代码。这与你 RouterClient 的「路由先于推理」、TokenBudget 的预算门禁、以及 fail.jsonl 记录失败用例的 QA 口径高度同频，建议拿 [AgentWeave](https://arxiv.org/abs/2608.23078) 与 [AutoSaddler](https://arxiv.org/abs/2608.23041) 对照现状，看能否把「候选集构造」与「harness 故障信号→持久补丁」沉淀成可复用模块。
2. **Signal or Noise? Agent Skills 在 Web 开发中的基准（M0 直接相关）** — 31 个公开 WebDev Skill 实测多数反而降分增 token，结论是「技能注入」应是 per-deployment 的路由决策而非可移植资产。这直接挑战 M0 阶段「把框架约定写成 SKILL.md 注入」的默认假设，建议把论文的「长度匹配对照 + 逐模型审计」当成 M0 技能评估的最低标准，避免被「加了技能就更好」的直觉误导。原文：[arXiv:2608.23067](https://arxiv.org/abs/2608.23067)。
