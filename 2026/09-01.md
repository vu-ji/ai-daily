## 【arXiv 精选】

### 论文 / 研究亮点（cs.AI、cs.CL 当日新提交，聚焦 Agent / 工具调用 / 记忆 / 推理控制）
- [Logos：跨进程总线上的 Agent Harness](https://arxiv.org/abs/2608.28553) — 把 agent 运行框架架在跨进程消息总线上，scaffold 无关，天然支持多运行时协作。
- [EvoUndo：可恢复约束的 LLM Agent Harness 自我进化](https://arxiv.org/abs/2608.28363) — 给 harness 的自我进化加「可恢复性约束」，避免演化过程不可逆损坏已有能力。
- [openJiuwen：超越静态 Harness 的长时程编程 Agent](https://arxiv.org/abs/2608.27969) — 面向长时程编码任务的动态 harness，突破静态 scaffold 的上下文与状态瓶颈。
- [GOD：Agent 社会的实时控制室（治理/观测/指导）](https://arxiv.org/abs/2608.27992) — Govern-Observe-Direct 三位一体运行时，对应 Agent 社会的实时治理与可观测。
- [多 Agent 失败归因反思框架](https://arxiv.org/abs/2608.28264) — 基于自动化失败归因的多智能体协作反思，定位「责任落到哪」而非笼统 retry。
- [Learning to Use Tools：工具集成数学推理的强化学习](https://arxiv.org/abs/2608.28447) — 用 RL 让模型真正「学会」在推理链中何时、如何调用工具。
- [AERA：自适应证据残差分配做高效测试时推理](https://arxiv.org/abs/2608.27964) — 动态分配证据权重提升推理效率，缓解盲目长链思维的成本。
- [SABER：稳定感知的 LLM 早退推理控制](https://arxiv.org/abs/2608.27963) — 通过对抗分支探测决定何时早退，在保精度下砍掉冗余推理步。
- [ContextPilot：细粒度 RL 训练 Agent 做主动上下文管理](https://arxiv.org/abs/2608.28476) — 让 agent 自己决定何时压缩/检索/丢弃上下文，而非被动等长窗截断。
- [PersonaForge：Agent 系统的真实多轮用户模拟器](https://arxiv.org/abs/2608.28378) — 生成逼真多轮用户行为，是评测/红队 Agent 的低成本「用户替身」。
- [实体-记忆图检索提升长对话问答证据覆盖](https://arxiv.org/abs/2608.27925) — 把记忆组织成实体图做检索，长对话 QA 证据召回明显优于扁平历史。
- [Agent 记忆如何处理「不可回答」问题才可靠？](https://arxiv.org/abs/2608.27924) — 研究记忆对拒答/不可答问题的边际贡献，给记忆层设计立了验收标尺。
- [LandingAgent：落地页生成的 Agent 框架与标注数据集](https://arxiv.org/abs/2608.27902) — 参考标注驱动的落地页生成 agent，直接对接前端工程师的存量能力。
- [解码语言模型做可靠 RAG（Knowing Before Answering）](https://arxiv.org/abs/2608.27661) — 先解码模型「知不知道」再决定检索，降低 RAG 的无效召回噪声。
