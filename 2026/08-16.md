## 【arXiv 精选】

- [RippleMem: From Isolated Retrieval to Associative Recollection for Long-Term Agent Memory](https://arxiv.org/abs/2608.13334) — 从孤立检索走向关联回忆的长期 Agent 记忆（cs.CL），记忆质量不再只靠向量相似度。
- [When Your Agent Opens the Chat App: Agent-Controlled Search over Raw Chat Logs Rivals Structured Memory](https://arxiv.org/abs/2608.12888) — 让 Agent 自己搜原始聊天记录，效果媲美结构化记忆（cs.CL），给「记忆即检索」新思路。
- [Beyond Retrieval: Query-Conditioned Reuse of Long-Horizon Agent Trajectories](https://arxiv.org/abs/2608.12847) — 查询条件化复用长周期 Agent 轨迹（cs.AI），超越 RAG 范式把历史经验当可调资源。
- [SkillShapley: Boundary-Adaptive Shapley Valuation for Skill Step Attribution in LLM Agents](https://arxiv.org/abs/2608.13173) — 边界自适应 Shapley 估值做技能步骤归因（cs.AI），可定位 Agent 哪一步技能在拖后腿。
- [Teach the Magnitude, Not the Direction: Verifier-Bounded Credit Assignment for Multi-Turn Multi-step LLM Agents](https://arxiv.org/abs/2608.13179) — 验证器受限的信用分配（cs.AI），训练多轮多步 Agent 关注「量级」而非方向。
- [Practice Makes Unsafe: Skill Misevolution in Self-Improving LLM Agents](https://arxiv.org/abs/2608.12851) — 揭示自我改进 Agent 因「练习」导致的技能误进化安全隐患（cs.AI），对齐 vuji 的「反思要谨慎」经验。
- [StateBridge: Training-free Hidden-state Alignment for Latent Communication in LLM Multi-Agent Systems](https://arxiv.org/abs/2608.13317) — 无训练对齐 LLM 隐藏状态实现多 Agent 潜空间通信（cs.AI），给多 Agent 协调省 token。
- [BoardroomAI: Dependency-Aware Human-Steerable Multi-Agent Deliberation](https://arxiv.org/abs/2608.13046) — 依赖感知、人类可操纵的多 Agent 议事系统（cs.AI），用演化决策图做可控协商。
- [Knowing When to Quit: Diagnosing and Training LLMs to Abort Futile Reasoning](https://arxiv.org/abs/2607.29211) — 诊断并训练 LLM 及时中止无谓推理（推理控制），给 Token 预算再加一道安全阀。
- [RAGSieve: Self-Referenced Local Contrast for Knowledge-Poison Detection in RAG](https://arxiv.org/abs/2608.13010) — 在 RAG 中用自参考局部对比检测知识投毒（cs.CL），直接相关 W6 RAG 管道的安全性。

## 今日值得深入

1. **DarwinX + AutoDesign（Agent Harness 的元进化）** —— 这两篇把「Agent 运行框架本身」当作可进化 / 可优化的对象（自然选择、元 harness 优化）。对照 vuji 正在做的 RouterClient / ToolExecutor / 三层路由，思考：你的执行层能否也设计成「可被搜索 / 进化的 harness」而非写死的逻辑？建议从 [DarwinX](https://huggingface.co/papers/2608.07545) 与 [AutoDesign](https://huggingface.co/papers/2608.13560) 入手。
2. **长期记忆三连击（LycheeMemory V2 / RippleMem / When Your Agent Opens the Chat App）** —— 今日记忆方向三篇齐发，分别覆盖语义段级整合、关联回忆、让 Agent 自搜聊天记录。正是 WorkMusic W6 RAG + Memory 要回答的「什么该记、怎么记、怎么捞」三问。建议以 [RippleMem](https://arxiv.org/abs/2608.13334) 为主，对照 [LycheeMemory V2](https://huggingface.co/papers/2608.12990) 设计自己的记忆写入闸门与整合策略。
