## 【arXiv 精选】

### cs.CL（Fri, 4 Sep 2026）
- [RuleMem: Active Rule Memory for Long-Term Conversational Agents](https://arxiv.org/abs/2609.03915) — 给长程对话 Agent 主动维护"规则记忆"，避免重复犯错。
- [Remember and Reweight: Multi-Agent Debate with Experience Memory](https://arxiv.org/abs/2609.03619) — 多 Agent 辩论引入经验记忆 + 置信度重加权，提升协作质量。
- [When Users Don't Ask: Benchmarking Context-Driven Memory Retrieval](https://arxiv.org/abs/2609.03454) — 评测对话 Agent 在用户没明说时的上下文驱动记忆召回能力。
- [Lngram v2: Latent N-Gram Memory](https://arxiv.org/abs/2609.03410) — 用可解释离散表征做潜空间 N-gram 记忆，兼顾记忆与可解释性。
- [</think> Doesn't Stop Reasoning: Spurious CoT Termination](https://arxiv.org/abs/2609.03633) — 揭示 `</think:6124c78e>` 标签并不能真正终止推理，CoT 终止存在伪信号风险。
- [Random Attention: Rethinking KV Cache Eviction for Efficient Reasoning](https://arxiv.org/abs/2609.03426) — 重审 KV Cache 淘汰策略，服务高效推理。
- [SGD-KV: Summarization Guided KV Cache Compression](https://arxiv.org/abs/2609.03235) — 用摘要引导压缩 KV Cache，长上下文推理成本控制。
- [Legibility is Not Interpretability: Judged vs Actual Importance in CoT](https://arxiv.org/abs/2609.04194) — CoT 里"看起来重要"≠"真的重要"，提醒别被推理链可解释性误导。

### cs.AI（Fri, 4 Sep 2026）
- [The Natural Language Interaction Protocol and Standard for AI Agents](https://arxiv.org/abs/2609.04135) — 提出 AI Agent 自然语言交互协议与标准，直指 Agent 互操作。
- [Terminal-Universe: Turning Agent Trajectories into Scalable Terminal Environments](https://arxiv.org/abs/2609.04148) — 把 Agent 轨迹转成可扩展终端训练环境，利好 coding agent 评测。
- [DRACO: Fine-Grained Credit Assignment for Long-Horizon Agent Training](https://arxiv.org/abs/2609.04094) — 用动态 rubric 做长程 Agent 训练的细粒度信用分配。
- [Instruction Duplication as an Inference-Time Control Primitive](https://arxiv.org/abs/2609.04024) — 把"指令重复"当作推理时控制原语，无需重训即可影响输出。
- [Value-Preserving Architectures for Agentic AI Systems](https://arxiv.org/abs/2609.03920) — 面向 Agent 系统的价值保持架构，强调可控与保值。
- [Proactive Service Agents: A Unified Decision Framework](https://arxiv.org/abs/2609.03727) — 主动服务 Agent 的统一决策框架与评测方法。

## 今日值得深入

1. **Agent 记忆机制（RuleMem + Context-Driven Memory Retrieval）** — 两篇 cs.CL 同时指向"长程对话 Agent 怎么记住并主动召回规则/上下文"。对你本地优先 Agent（Loomry Studio / CloudNotes 的 RAG 记忆）直接可借鉴：规则记忆 vs 被动检索的取舍、用户没明说时如何触发召回。→ [RuleMem](https://arxiv.org/abs/2609.03915) · [When Users Don't Ask](https://arxiv.org/abs/2609.03454)
