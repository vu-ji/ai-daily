## 【arXiv 精选】

### cs.AI
- [The Natural Language Interaction Protocol and Standard for AI Agents](https://arxiv.org/abs/2609.04135) — 提出面向 AI Agent 的自然语言交互协议与标准，属于 Agent 框架基础设施。
- [DRACO: Fine-Grained Credit Assignment for Long-Horizon Agent Training](https://arxiv.org/abs/2609.04094) — 动态 rubric 实现长程 Agent 训练的细粒度信用分配，提升复杂任务学习效率。
- [Instruction Duplication as an Inference-Time Control Primitive](https://arxiv.org/abs/2609.04024) — 将指令重复作为一种推理时控制原语，探索轻量级的推理行为调控手段。
- [KC-Bench: Evaluating Knowledge Conflicts in LLM Agents](https://arxiv.org/abs/2609.03588) — 构建动态交互基准，评估 LLM Agent 在知识冲突下的表现。
- [Proactive Service Agents: A Unified Decision Framework](https://arxiv.org/abs/2609.03727) — 提出主动服务 Agent 的统一决策框架、方法与评估体系。

### cs.CL
- [RuleMem: Active Rule Memory for Long-Term Conversational Agents](https://arxiv.org/abs/2609.03915) — 主动规则记忆机制，让长期对话 Agent 动态存储并应用交互规则以增强一致性。
- [When Users Don't Ask: Context-Driven Memory Retrieval Benchmark](https://arxiv.org/abs/2609.03467) — 基准测试对话 Agent 在用户未显式提问时主动做上下文驱动记忆检索的能力。
- [Remember and Reweight: Multi-Agent Debate with Experience Memory](https://arxiv.org/abs/2609.03619) — 引入经验记忆模块与置信度估计，增强多 Agent 辩论的鲁棒性。
- [</think> Doesn't Stop Reasoning: Spurious CoT Termination](https://arxiv.org/abs/2609.03633) — 揭示模型在生成终止符后仍在内部继续推理的虚假终止现象。
- [Lngram v2: Latent N-Gram Memory with Interpretable Discrete Representations](https://arxiv.org/abs/2609.03426) — 用可解释离散表示实现潜在 N-Gram 记忆，增强知识记忆能力。

## 今日值得深入

1. **[funes：本地优先的 Agent 记忆层](https://huggingface.co/blog)** —— HF 把 coding agent 的会话轨迹做成混合向量 + BM25 的本地索引，跨机同步、云无关。这与你 local-first Agent（Loomry Studio / CloudNotes）的记忆设计直接对接：可借鉴其「原始证据保留 + 重排」而非摘要式记忆的思路。
2. **[RuleMem：长期对话 Agent 的主动规则记忆](https://arxiv.org/abs/2609.03915)** —— 让 Agent 在长程对话中动态提炼并应用交互规则，是「记忆如何驱动一致性」的近邻研究；配合 `When Users Don't Ask`（上下文驱动检索基准）一起读，能补全你记忆层「什么时候该主动回忆」的设计。
