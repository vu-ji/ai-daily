## 【arXiv 精选】

### Agent / 工具调用 / 记忆 / 推理控制（cs.AI）
- [Measure Before You Manage: Evaluating Agent Working Memory in Coding Agents](https://arxiv.org/abs/2608.31057) — 提出「先评估后管理」，度量编程智能体的工作记忆能力，直接命中 Agent 记忆评测。
- [Token-Efficient Data Reasoning Agents via Adaptive Structuring of Unstructured Data](https://arxiv.org/abs/2608.31082) — 对非结构化数据做自适应结构化，构建令牌高效的数据推理智能体（企业数据问答降本）。
- [ATLAS: Dual-Horizon Diagnostic Evaluation for Industrial Tool-Use Agents](https://arxiv.org/abs/2608.30685) — 面向工业工具使用智能体的双视野诊断评估框架。
- [Covert Indirect Prompt Injection on Tool-Using LLM Agents](https://arxiv.org/abs/2608.30362) — 研究工具使用型 LLM Agent 上的隐蔽间接提示注入，工具调用安全必读。
- [Reconciling Process Supervision with Outcome-Based Credit in Agentic Policy Optimization](https://arxiv.org/abs/2608.31077) — 在 Agent 策略优化中协调过程监督与结果信用分配，推理控制 + 训练。
- [SkillZip Pro: Execution-Aware Dynamic Compression of Progressively Loaded Skills for Self-Evolving Agents](https://arxiv.org/abs/2608.30785) — 自进化 Agent 的执行感知技能动态压缩与渐进加载，记忆 / 技能管理方向。

### LLM / 推理 / 记忆（cs.CL）
- [Learning to Evaluate Before Improving: Automatic Rubric Induction for Automatic Research Agents](https://arxiv.org/abs/2608.31076) — 自动研究 Agent 中「先评估后改进」的自动评分标准归纳方法。
- [TopoCompress: Long Context Compression via Graph-Wired Semantic Trajectories](https://arxiv.org/abs/2608.30811) — 通过图连接语义轨迹压缩长上下文，LLM 记忆 / 上下文管理。
- [What It Costs to Compose, Rebuild, and Correct Precomputed Memory](https://arxiv.org/abs/2608.30647) — 分析组合、重建、纠正预计算记忆的代价，LLM 记忆机制底层研究。
- [SwarmBench: Can Large Language Models Act as Agent Swarm Orchestrators?](https://arxiv.org/abs/2608.30661) — 测试 LLM 能否作为智能体群编排者的基准。
- [LCoT-GV: Graph Attention Networks for Verifying Long Reasoning Chains in LLMs](https://arxiv.org/abs/2608.30679) — 用图注意力网络验证 LLM 长推理链的正确性，推理可靠性方向。
