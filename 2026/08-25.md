## 【arXiv 精选】

- [Don't Solve, Just Compare: Tiny Advisors for Runtime Intervention in LLM Agents](https://arxiv.org/abs/2608.21027) — COTA：用一个弱得多的「比较器」判断采样分支是否优于执行者当前提案，重复比较决定是否介入并给出非绑定建议，让原 Actor 自己重规划；WebShop/ALFWorld/τ³-Retail 上九项评估全部提升。
- [TRACE: Agentic Catalog Enrichment with Multi-source Evidence Grounding](https://arxiv.org/abs/2608.20844) — ScoutAgent 跨商家目录/聚合源/网页搜索三角化多模态证据提候选属性，JudgeAgent 对照证据核验并决定发布或转人工；离线 98.2% 准确率、74.7% 覆盖，上线后结账转化 +0.48%。
- [CAS: Conformalized Agentic Search via Adaptive Retrieval and Policy Weighting](https://arxiv.org/abs/2608.20771) — 把 Conformal Prediction 引入搜索 Agent 的 RL 微调：检索端用自适应预测集动态截断文档，训练端用 ACI 量化答案置信度并在 GRPO 中惩罚低置信轨迹，显著提准确率同时大幅减少冗余工具调用。
- [Memory Augmentation Unlocks Efficient Chain-of-Thought Reasoning](https://arxiv.org/abs/2608.21265) — 提出「上下文-生成替代律」，用免训练的记忆增强压缩：从历史 trace 建可复用推理记忆当 prefill 侧脚手架；相对 Chain-of-Draft 在 GSM8K/MATH/BBH/MMLU-Sci 涨 21.4~29.5 分，延迟 1.14~1.49× 加速。
- [ForeDreamer: A Self-Evolving Dual-Agent Memory Architecture for Future Event Prediction](https://arxiv.org/abs/2608.20920) — 把原始网页证据先转成结构化记忆再做预测：事实记忆（当前预测的问题专属证据态）+ 经验记忆（跨轮累积），主 Agent 搜索预测、记忆子 Agent 用专门工具把结果转成事实记忆（EMNLP 2026 Findings）。
- [Tree-of-Concerns: Hierarchical Multi-Agent Debate for Unstated-Limitation Extraction](https://arxiv.org/abs/2608.20777) — 部署专门「怀疑者」人设作为并行辩论树提取科学论文未述局限，Panel Review 纠正类别漂移；ToC-Bench 上相对最强基线精度 +79%、覆盖 +11%（EMNLP 2026 Findings）。
- [When Failures Propagate: Causal Failure Attribution in Agentic RAG](https://arxiv.org/abs/2608.20627) — AgenticRAG-FP 干预基准：在指定 hop 注入确定性故障并重跑下游轨迹，检验事后 trace 能否定位注入点；发现传播深度本身就是诊断 Agentic RAG 失败的独立评估轴（hop1 覆盖 0.91、hop2/3 掉到 0）。

## 今日值得深入

1. **[Graph Engineering in the Era of LLM Agents](https://huggingface.co/papers/2608.21156) + [Don't Solve, Just Compare / COTA](https://arxiv.org/abs/2608.21027)** — 一条讲「怎么组织多 Agent 系统」（显式图结构 + 系统智能，对应 vuji 云笺/WorkMusic 里多个 TS Agent 的协作），一条讲「怎么不重训就提升单 Agent 可靠性」（弱比较器做运行时介入、给非绑定建议让原 Actor 重规划）。对照你的现状：把多 Agent 协作从「prompt 里凑」改成「显式图 + 状态」，再把 RetryController 从「硬重试」升级成「比较候选分支后给非绑定建议」——正好是当前阶段的两块拼图，且 COTA 的「合法但未达成状态变更」判定可直接接进 fail.jsonl 的失败分类。
2. **[CAS](https://arxiv.org/abs/2608.20771) + [Memory Augmentation CoT](https://arxiv.org/abs/2608.21265)** — CAS 给「工具调用可靠性」一个形式化框架（保形预测量化置信度、在 GRPO 里惩罚低置信轨迹、减少冗余工具调用），与你 TokenBudget / 工具调用预算控制同频；Memory Augmentation 则证明「把历史推理模式当 prefill 脚手架」能在不训练的情况下补回压缩掉的逻辑——可借鉴到你 WorkMusic 的 RAG 检索上下文压缩，作为压缩后的逻辑保真兜底。
