## 【arXiv 精选】

- [Pandora's AI Model Routing Box: Efficient Allocation with Costly Value Estimation](https://arxiv.org/abs/2608.20316) — 把"多专家路由"建模为 Pandora's Routing 最优搜索问题，用"信息价值"决定何时值得调用昂贵的精算器，路由质量持平穷举却大幅减少昂贵评估调用（与 RouterClient / TokenBudget 思路同频）。
- [Optimal Skill Selection for LLM Agents with Provable Bicriteria Guarantees](https://arxiv.org/abs/2608.19993) — 首次将"技能集选择"形式化为带 token 预算的单调子模优化，提出多项式时间 BPS 算法，在更少 token 下任务成功率 0.73 远超基线 0.20–0.52（技能装进有限上下文的成本-收益量化）。
- [Can Agent Memory Systems Track Evolving State?](https://arxiv.org/abs/2608.19652) — 指出记忆系统关键能力是"状态追踪"（事实被修订后答案须反映当前态而非旧态），StateMem 方法在 DeepSeek-V4-Flash 上将当前态准确率提升 1.8×。
- [Break It Down, Pass It On: Cross-Task Skill Transfer in LLM Agents](https://arxiv.org/abs/2608.20274) — 受控实验发现：子任务级技能比任务级技能更能提升迁移、文本技能优于代码技能，并提出无需执行即可诊断技能可用性的"技能效用分数"。
- [Learning When to Think: Adaptive Reasoning for Test-Time Compute Allocation](https://arxiv.org/abs/2608.20256) — 让 1.5B 模型在 GRPO 中自学会选 NoThink / Short / Long 三种推理模式，MATH500 精度持平但平均回复长度砍掉 41%、GSM8K 省 76% token（推理预算自适应，正是 TokenBudget 想做的）。
- [EnvHarness: Awakening Static Worlds for Agent Learning](https://arxiv.org/abs/2608.19880) — 用可编程插件层包裹静态环境、按智能体弱点自动重塑（EnvRigger 黑盒诊断 + 新 rollout 验证），五基准最高 +9.0 分且策略与环境协同进化。
- [SWE-bench Science: Can Coding Agents Resolve Engineering Tasks in Science?](https://arxiv.org/abs/2608.19799) — 119 道科学软件仓库级任务，最强 Claude Code Opus-5 pass@1 仍 <50%，定位四类失败机制（科学抽象 / 表面修复 / 集成不全 / 泛化失败）。
- [ReCache: Efficient KV Cache Reuse and Compression for Tool-Augmented LLM Agents](https://arxiv.org/abs/2608.19662) — 资源级注意力解耦工具 / 技能 schema 的 KV 缓存，内存分配降 92.43%、首 token 提速 3.655×，几乎不损效果（Agent 推理降本直接抓手）。
- [MemTrapBench: Benchmarking Cognitive Traps in LLM Memory Use](https://arxiv.org/abs/2608.20202) — 系统基准测试 LLM 记忆使用中的"认知陷阱"，量化记忆机制何时反而拖累表现。
- [AI4AI-Bench: Benchmarking LLM Agents in Algorithmic Design for Recursive Self-Improvement](https://arxiv.org/abs/2608.20318) — 评估 LLM Agent 在算法设计中的"递归自我改进"能力，为自改进智能体立基准。
