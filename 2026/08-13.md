## 【arXiv 精选】

> 链接统一为 https://arxiv.org/abs/XXXX.XXXXX，聚焦 Agent / 工具调用 / 记忆 / 推理控制。

- [Why Does CLAUDE.md Keep Growing? Catastrophic Remembering in Agentic Coding](https://arxiv.org/abs/2608.11095) — 直击 Agentic Coding 痛点：记忆文件（CLAUDE.md 类）只会膨胀、不会清理，导致"灾难性记忆"，给出量化与缓解思路。
- [MAP-Graph: Provenance-Aware Shared Memory for Multi-Agent Workflows](https://arxiv.org/abs/2608.10509) — 为多智能体工作流设计带溯源的共享记忆，解决跨 Agent 状态一致与可审计问题。
- [From Faulty Memories to Corrected Actions: Dependency-Guided Rollback Repair](https://arxiv.org/abs/2608.10502) — 面向记忆增强 Agent 的依赖引导回滚修复，记忆出错时精准撤销而非整体重置。
- [EvoMem: Memory-Augmented Evolution for Code Optimization](https://arxiv.org/abs/2608.10795) — 记忆增强的演化式代码优化，把历史成功解作为演化先验。
- [Self-Correcting Long-Horizon Search Agents via Tree-Structured Memory](https://arxiv.org/abs/2608.10676) — 用树状结构记忆支撑长程搜索 Agent 的自纠错，缓解中途迷失。
- [Continuous Interaction Diffusion: A Diffusion-Native Runtime for Asynchronous Tool-Augmented Reasoning](https://arxiv.org/abs/2608.10438) — 提出扩散原生的异步工具增强推理运行时，让工具调用与推理并行解耦。
- [REDAgentBench: Executable Red Teaming and Faithful Measurement of LLM Agent Systems](https://arxiv.org/abs/2608.10669) — 可执行的 Agent 红队基准，真实环境度量 LLM Agent 系统的攻击面与鲁棒性。
- [Actions Speak Louder than Words: Cross-Lingual Policy Retention in Tool-Using Agents](https://arxiv.org/abs/2608.11110) — 测工具调用 Agent 的跨语言策略保持，揭示"会说"≠"会做"的偏差（COLM 26）。
- [Mitigating Context Interference for Reliable and Efficient Search Agents](https://arxiv.org/abs/2608.10743) — 缓解搜索 Agent 的上下文干扰，提升长链路检索的可靠性与效率。
