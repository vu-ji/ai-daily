## 今日值得深入

1. **[Kimi-K3 开源](https://huggingface.co/moonshotai/Kimi-K3)** — 不只是「最大开源模型」：它原生面向 Agent 设计（工具调用、网页浏览、多步规划内建），且在 Frontend Code 榜登顶。重点读它的技术报告和随之开源的 **AgentEnv**（Agent 训练环境 Infra），理解前沿实验室如何定义「Agent 原生模型」，这决定了上层框架未来一年的接口形态。
2. **[Mastra 生产级 Agent 实战教程](https://dev.to/thegdsks/building-a-production-ai-agent-in-typescript-with-mastra-a-2026-step-by-step-37dc)** — 对前端转型最实操的一篇：Memory 的 resource/thread 会话模型、LibSQL→Turso 无缝切生产、`response.usage` 成本监控，这些正是从「Demo Agent」到「生产 Agent」的分水岭。建议跟着跑一遍并部署到自己的 Express/Next.js 服务里。
