## 【arXiv 精选】

### 论文 / 研究亮点（cs.AI、cs.CL 当日新提交，聚焦 Agent / 工具调用 / 记忆 / 推理控制）

- [AgentRewind: Recoverable Execution for Long-Horizon LLM Agents](https://arxiv.org/abs/2608.14380) — 长程 Agent 的「可恢复执行」框架：执行出错时可回滚到检查点重跑，而非整轮推倒重来（19 页，工程化价值高）。
- [Demystifying Agent Skills: Why They Work-Until They Don't](https://arxiv.org/abs/2608.14036) — 首次系统拆解「Agent Skills」为何有效、在哪些条件组合下会失效，直接回应 skills 工程化落地的坑（vuji 当前学习重点强相关）。
- [Mandato: Protocol-Level Enforcement of Digitally Signed Mandates on AI Agent Actions](https://arxiv.org/abs/2608.14074) — 用密码学链式审计对 Agent 动作做「数字签名授权」协议层强制，解决「Agent 越权执行」的企业级信任问题。
- [Agent-Orchestration in Autonomous Chip Design](https://arxiv.org/abs/2608.14035) — 把多 Agent 编排用于自主芯片设计，展示 Agent 在硬核工程领域的端到端落地形态。
- [Handover of In-Context Learning State Across Session Boundaries](https://arxiv.org/abs/2608.14528) — 研究跨会话边界「交接」上下文学习状态，指向 Agent 记忆/状态的持久化与续接这一核心难题。
- [ScienceFlow: A long-horizon agent for ML research, scientific discovery and beyond](https://arxiv.org/abs/2608.14354) — 面向 ML 科研的长程 Agent，把假设生成、实验、验证串成自主科研闭环。
- [Clearing the Fog: Installing and Refining Proactive Exploration Capabilities in LLM Agents](https://arxiv.org/abs/2608.14339) — 给 LLM Agent 装上与精炼「主动探索」能力，让 Agent 不再被动响应、能主动发现信息缺口。
- [Repair, Not Improvement: Decomposing Constrained Decoding in Tool-Call Abstention](https://arxiv.org/abs/2608.13959) — 把工具调用「放弃调用」场景的约束解码拆成「修复」而非「改进」，提升 LLM 工具调用的可靠性（cs.CL）。
- [BCMT: Blockwise Causal Memory Transformer](https://arxiv.org/abs/2608.13578) — 分块因果记忆 Transformer，用结构化记忆机制增强长程依赖，可作为 Agent 记忆模块的底模思路（cs.CL）。
- [Does a Language Server Save Tokens for Coding Agents?](https://arxiv.org/abs/2608.13568) — 用测量方法论研究「语言服务器（LSP）能否为编程 Agent 省 token」，量化工具交互对编码 Agent 成本的影响（cs.CL，前端→Agent 实用）。
- [Not All Tokens Are Equal: Inflation-Aware Routing for Agentic LLM Systems](https://arxiv.org/abs/2608.13571) — 提出「通胀感知」路由机制优化多 Agent 系统的 token 分配，呼应 Agent 成本控制这一落地痛点（cs.CL）。
- [Envs-FORGE: Frontier-Optimized Reward-Grounded Environment Synthesis for Agent RL](https://arxiv.org/abs/2608.14312) — 面向 Agent 强化学习的「奖励驱动环境自动合成」，降低训练环境的构建成本（cs.CL）。

## 今日值得深入

1. **[Demystifying Agent Skills: Why They Work-Until They Don't](https://arxiv.org/abs/2608.14036)** — 你现在 M0 就在系统学 pi-agent 的 Skills 范式，这篇是社区首次对「技能为什么有效、什么组合下会翻车」做系统归因，建议作为 skills 设计的对照基线，避免踩坑。
