## 今日值得深入

> 以下两条作为转型学习重点参考，建议精读。

1. **GUI Agent 是前端转型的最短路径：[Qwen-UI-Agent 技术报告](https://huggingface.co/papers/2607.28227) + [掘金 Next.js Agent 前端编排](https://juejin.cn/post/7653686112276348962)** — Qwen-UI-Agent 把「真实世界 GUI」做成基础智能体，模型直接消费页面截图与操作流；而前端工程师对 DOM 结构、交互状态、事件流的直觉，恰好是 GUI Agent 时代最稀缺的领域知识。配合掘金这篇把 Agent 循环 / SSE 流式 / 编排 UI 状态机拆开的中文实战，建议今天就把「给一个页面加 Agent 可操作步骤标注」跑通——这是证明你已切入 Agent 的最小可交付。

2. **Vercel AI SDK 7 的「持久执行」是 Agent 上生产的真正分水岭：[AI SDK 7 发布说明](https://vercel.com/changelog/ai-sdk-7)** — 过去 Agent demo 崩在「长任务中断 / 重启 / 人工审批」，v7 用 WorkflowAgent（持久执行 + 审批门）+ HarnessAgent（统一调度 Codex / Claude Code）+ @ai-sdk/tui 调试器一次性补齐。前端对「状态机、断点续传、乐观更新」的肌肉记忆，正好能直接复用到 agent 的 durable execution 上。建议精读 WorkflowAgent 与 `stopWhen` 两段，理解「Agent 循环控制」在生产里怎么落地。
