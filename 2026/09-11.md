## 【arXiv 精选】论文 / 研究亮点

- [Subagents vs Agent Skills: Executing Reusable Knowledge for Long-Horizon Agentic Tasks](https://arxiv.org/abs/2609.09233) — 对比「子 Agent」与「可复用 Skill」两种长程任务知识执行范式，**直接印证 pi-agent 的 Skill 架构选型**，值得精读。
- [ROAM: Robust Organization of Atomic Memories for Agents through Semantic Relations](https://arxiv.org/abs/2609.09778) — 用语义关系把原子记忆组织成结构，提升 Agent 记忆的鲁棒检索，对接 local-first Agent 记忆层设计。
- [ConvMem: Convolutional Memory for Long-Context Reasoning](https://arxiv.org/abs/2609.10441) — 用卷积式记忆机制服务长上下文推理，降低长程依赖的注意力开销。
- [Fortunate Recall: Ontology-Driven Memory Lifecycle Management for Persistent Coherence in LLMs](https://arxiv.org/abs/2609.10413) — 本体驱动的 LLM 记忆生命周期管理，解决跨会话持久一致性问题。
- [What Should an Agent Forget? Separating What Is Stored from What Is Used](https://arxiv.org/abs/2609.10263) — 区分「存储」与「使用」的记忆遗忘策略，为 Agent 记忆淘汰机制提供理论边界。
- [The Menu Is an Execution Prior: State-Path Tool Menus for Online Agents](https://arxiv.org/abs/2609.09395) — 用「工具菜单」作为在线 Agent 的执行先验（state-path），约束工具调用路径、降低探索成本。
- [JarvisGUI: Towards Cross-Device GUI Agents with Dynamic Task Composition](https://arxiv.org/abs/2609.10451) — 跨设备 GUI Agent，支持动态任务组合，EMNLP 2026 主会。
- [TRACE: Training Reasoning Agents for Causal Exploration with Synthesized Rewards](https://arxiv.org/abs/2609.10315) — 用合成奖励训练因果探索推理 Agent，强化「工具调用 → 因果推断」链路。
- [Stable Answers, Unfinished Reasoning: Why Self-Consensus Is Not a Safe Early-Exit Signal](https://arxiv.org/abs/2609.09989) — 指出「自我一致性高」并不等于推理完整，警示把自洽当作推理早退信号的隐患。
