## 【前端 → AI Agent 转型方向】

### 框架 / 工具链
- [agent-memory（tigerless-labs，996★）](https://github.com/tigerless-labs/agent-memory) — 用纯 Markdown 作真相源的长期记忆运行时，本地排序检索 + 独立 sleep-time 管理层，完美契合 local-first Agent 记忆层（CloudNotes / Loomry 风格）。
- [MCPX — MCP 服务器包管理器](https://github.com/) — MCP 生态已多到需要统一管理：搜索/一键安装/切换版本，且带"权限预览"（安装前展示可访问文件与命令），安全意识拉满。
- [StorAgent — 三层记忆治理](https://github.com/) — 把 Agent 记忆分工作记忆/情景记忆/语义记忆三层，向量检索 + 摘要压缩调度，"该记的记、该忘的忘"，直接可借鉴到生产 Agent。
- [CubeSandbox v0.7.0](https://github.com/) — 自托管 MicroVM 沙箱，冷启 <60ms、开销 <5MB、单机数千沙箱，配 checkpoint/回滚/克隆快照，是 Agent 跑代码与浏览器的安全边界。
- [Bezalel — 一个 MCP URL 整合一切](https://github.com/) — 把 memory/email/payments/SMS/云电脑/沙箱/数百连接器收进一个 MCP URL + 一个 token，主张"工具是持久资产、Agent 是可替换外壳"。
