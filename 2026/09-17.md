## 【arXiv 精选】

- [ScienceBuddy: Recursive-in-Recursive Self-Improvement for Interactive Scientific Agents](https://arxiv.org/abs/2609.17523) — 交互式科学 Agent 的「递归中递归」自我改进框架，让 Agent 在科研任务中持续迭代自身能力。
- [Never Stop Thinking: Continuous-Time Language Agents](https://arxiv.org/abs/2609.17416) — 提出连续时间语言 Agent，突破离散 token 步的推理节奏，面向长时程自主任务。
- [EchoPath: Execution-Level Replayable Memory for GUI Agents](https://arxiv.org/abs/2609.16635) — 为 GUI Agent 设计「执行级可回放记忆」，把操作轨迹存为可重放的上下文，解决跨会话遗忘。
- [ThinkFlow: Self-Evolving Probabilistic Latent Memory for Lifelong Conversational Agents](https://arxiv.org/abs/2609.17010) — 用概率潜变量建模终身对话记忆并自我演化，减少记忆膨胀与遗忘。
- [LSREP: Longitudinal State-Replay Protocol for Conversational Memory, with ICE v2 as an Audited Local-First Architecture](https://arxiv.org/abs/2609.16730) — 提出对话记忆的「纵向状态重放」评测协议，并以 ICE v2 作为可审计的 local-first 记忆架构参考实现（★ 直接对接本地优先 Agent 记忆层）。
- [Interactive Memory Learning for Long-Term Conversations](https://arxiv.org/abs/2609.17088) — 面向长期对话的交互式记忆学习，平衡回忆准确度与存储成本。
- [Persistent Recurrent Memory Between Transformer Layers](https://arxiv.org/abs/2609.17251) — 在 Transformer 层间插入持久循环记忆，提升语言模型泛化，从架构层缓解上下文窗口限制。
- [When Should LLMs Abstain? Chain-of-Self-Questioning for Selective Risk Control](https://arxiv.org/abs/2609.17516) — 用「链式自我提问」让 LLM 自主判断是否该拒答，做选择性风险控制，是推理控制 / 安全护栏方向。
- [The Router Within: Eliciting Native Skill Routing from a Frozen LLM](https://arxiv.org/abs/2609.15982) — 从冻结 LLM 中引导原生技能路由，无需微调即可实现工具 / 技能分发，呼应 Agent 的 tool-calling 边界。
