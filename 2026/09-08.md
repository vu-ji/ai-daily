## 【arXiv 精选】

> cs.AI / cs.CL 当日新提交，聚焦 Agent / 工具调用 / 记忆 / 推理控制（9/7 批次）。

- [Multi-Step Tool-Calling over Korean Open Public APIs](https://arxiv.org/abs/2609.05395) — 多步工具调用基准 + 数据合成方法（已收 EMNLP 2026），工具调用方向的核心评测。
- [Does Your Agent's Memory Survive a Model Upgrade?](https://arxiv.org/abs/2609.05339) — 受控实验研究 Agent 记忆在底层模型升级时的可移植性，直接戳中「记忆与 provider 解耦」这一 local-first 设计痛点。
- [Trace2Tower: Transition-Aware EigenTrace Induction of Multi-Level Skills](https://arxiv.org/abs/2609.05261) — 轨迹感知的多级技能提取，把 Agent 历史 trace 归纳成可复用的层级技能。
- [TROVE: Adaptive Agent Skill Orchestration](https://arxiv.org/abs/2609.05019) — 通过轨迹验证与编辑实现自适应技能编排与规划，提升 Agent 长任务执行可靠性。
- [Compact-Memory LLM Agents via Online Max-Member Clustering](https://arxiv.org/abs/2609.04915) — 在线聚类 + 原子感知打包，为 LLM Agent 做紧凑型记忆管理，降低长程记忆成本。
- [CUA-Universe: Hybrid GUI+CLI Agents Environment](https://arxiv.org/abs/2609.05374) — 可扩展、动态的混合 GUI+CLI Agent 训练/测试环境，贴近真实操作场景。
- [Substrate-Aware AI Agents: Execution Context as a First-Class Input](https://arxiv.org/abs/2609.05232) — 主张把执行上下文（substrate/运行环境）作为一等输入，让 Agent 更感知所处环境。
- [Beneath the Surface of Chains-of-Thought](https://arxiv.org/abs/2609.04753) — NAVER/KAIST 对 LLM 思维链推理操作的机制可解释性剖析，理解推理何以发生。
- [RefactorPlatform: Controlled Evaluation of Repository-Scale Refactoring Agents](https://arxiv.org/abs/2609.04898) — 开源评测平台，对仓库级代码重构 Agent 做受控评估，coding agent 转型实用参考。

## 今日值得深入

1. **Agent 记忆机制（可移植 + 紧凑）** — 重点读 [arXiv 2609.05339「Does Your Agent's Memory Survive a Model Upgrade?」](https://arxiv.org/abs/2609.05339) 与 [2609.04915「Compact-Memory LLM Agents」](https://arxiv.org/abs/2609.04915)：前者验证「记忆与底层模型/provider 解耦」的必要性，后者给出现代化紧凑记忆的工程做法。直接对接你 local-first Agent 的记忆层设计（原始证据保留 + 重排 + provider 切换不丢失）。
2. **Funes 本地优先记忆层** — 见 [HF Funes](https://futurepedia.io/ai-innovations/hugging-face)：coding agent 的本地索引持久记忆，是「记忆留本地、模型可替换」思路的现成参考实现，可作为你 CloudNotes / Loomry 类 local-first 项目的记忆层样板。
