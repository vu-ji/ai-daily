## 【arXiv 精选】（cs.AI / cs.CL，11-13 批次）

- [CoReMem: Cost-Internalizing Memory for Successive Coding Tasks with Prospective Valuation](https://arxiv.org/abs/2611.17316) — 耶鲁：把记忆的读写成本内化进训练目标——「前瞻估值」对比有无某轨迹段的下一任务表现，只保留锚定仓库位置与可执行检查的紧凑记忆；27B actor 解决率 21.0%→25.7%、步数 -17%、总 token -11%。
- [Discovering Effective Agent Memory Designs through Program Evolution](https://arxiv.org/abs/2611.17068) — NeurIPS 2026：MAPE 用程序进化从最小种子自动演化整套记忆程序，比手工设计高 12% 且 serving 成本仅 35%；实证两个可迁移模式——保留原始对话作可检索证据、按查询意图组合证据，后者移植进 5 个现有记忆系统全部涨点。
- [Skill Adapter: Personalized Modification and Online Routing of General-Purpose Skills](https://arxiv.org/abs/2611.17007) — 通用 skill + 个人 Adapter 双层架构：从用户需求与执行反馈蒸馏本地调整挂到通用 skill 上，路由 Agent 按子任务在线选择并预取后续节点；比 SkillRL 平均 +11.43pp，skill 池扩到 1000 仍保持优势。
- [Folio: Recoverable Multi-Resolution Context Folding for Long-Horizon Language Agents](https://arxiv.org/abs/2611.16627) — 可恢复的上下文折叠：L1 轮次笔记 / L2 事件清单 / L3 原始记录三层 handle，折叠由运行时程序化完成（中位 0.6s）而非模型重写，恢复工具按需翻页取证；LOCA-bench 66 题 vs Claude Code 49-59，成本仅 1/2.4。
- [HeMeR: Heterogeneous Memory Reconciliation for Embodied Agents via Structured KV Reuse](https://arxiv.org/abs/2611.16487) — NeurIPS 2026 Oral：陈述性 / 程序性 / 工作记忆异构统一，只对内容变化的部分做 KV 重算；真机任务成功率 83.2%，单步推理 2.94s→1.87s——记忆系统工程的推理侧优化。
- [Singularity-Bench: Can Agents Build Agents?](https://arxiv.org/abs/2611.16591) — 「Agent 造 Agent」开放基准：预训练 / 中训练 / 后训练 / 推理 / harness / 集群编排六个端到端任务对标人类基线；Opus 5.5 + Claude Code 拿到 Singularity-Index 1.25，其余 10 个 Agent 平均仅 0.58；红队测试暴露 Harbor 框架奖励 hacking 漏洞并给出 Breakwater 补丁。
- [Experience-Handoff Reinforcement Learning for Recursive Self-Improvement](https://arxiv.org/abs/2611.16409) — KAIST：训练模型写「经验交接工件」（playbook），按其对未来 rollout 的下游效果优化——RL 不只优化当前动作，也优化留给未来的记忆，标量奖励与环境信息两手抓。
- [How Should Planning Agents ReSHAPE Their Search Space?](https://arxiv.org/abs/2611.16466) — CMU：规划 Agent 应把用户请求当假设检验——展示具体方案比询问偏好能多接纳 52%+ 可接受计划（现有 Agent 仅 32%），旅行场景 F1 +9.7；5800 个修订规格实证「搜索空间质量预测规划结果」。
- [Evidence-Guided Recovery for AI Agents with Ambiguous Tool Outcomes and Partial Execution](https://arxiv.org/abs/2610.41453) — 工具超时导致「结果模糊 + 部分执行」时的证据引导恢复：共享可采纳性检查（密钥过期 / 授权时序 / 依赖 / 残留效应）+ 终止证书区分真实完成与表面安全完成；30 vs 9 完成认证（+36.2pp，p=0.0078），116 条轨迹全部通过独立回放。
