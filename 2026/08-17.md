## 【arXiv 精选】

> cs.AI / cs.CL 当日新提交（2026-08-17）中与 Agent / 工具调用 / 记忆 / 推理控制最相关的条目

- [AgentRewind: 长程 LLM 智能体的可恢复执行](https://arxiv.org/abs/2608.14380) — 长程 Agent 崩溃后可从断点恢复执行，直接对应"持久化/容错"工程命题
- [ScienceFlow: 面向机器学习研究的长程智能体](https://arxiv.org/abs/2608.14354) — 19 人团队的长程科研智能体，自主读论文→跑实验→评估
- [Demystifying Agent Skills: Why They Work-Until They Don't](https://arxiv.org/abs/2608.14036) — 直击 Agent Skills 失效根因，对设计可复用工具/技能极有启发
- [SheetCompass: 分层关系图驱动的表格推理智能体](https://arxiv.org/abs/2608.14452) — 用关系图做 agentic 表格推理，前端数据表格场景可直接借鉴
- [Handover of In-Context Learning State Across Session Boundaries](https://arxiv.org/abs/2608.14528) — 跨会话边界的上下文学习状态交接，正是"Agent 记忆"的核心难题
- [BCMT: Blockwise Causal Memory Transformer](https://arxiv.org/abs/2608.13578) — 块级因果记忆 Transformer，模型层记忆机制新探索
- [Repair, Not Improvement: 工具调用弃权的约束解码分解](https://arxiv.org/abs/2608.13959) — 工具调用中"何时不调用"的约束解码，提升 Agent 工具使用可靠性
- [Think in Latent, Explain in Language: 自解释潜在推理](https://arxiv.org/abs/2608.13570) — 在潜在空间推理、用语言解释，推理可控性方向
