### 论文（Daily Papers Aug 18 批次）
- [StateM: 95.3% on Terminal-Bench 2.1 via Harness Scaling](https://huggingface.co/papers/2608.15089) — 不改模型权重、只做「harness 缩放」：用持久状态 / 可恢复 runbook 把 GPT-5.6 推到 95.3% raw accuracy，$15 跑完一轮，方向直指「执行层即护城河」。
- [HarnessEval-W: Agentifying the Evaluation of Visual Worlds](https://huggingface.co/papers/2608.16859) — 把 harness 范式引入世界模型评测：父 Agent 拆解问题、派生子 Agent 带诊断工具给出证据树，告别黑箱标量分数。
- [ClawGym II: Exploring Black-Box RL on Agent Harness](https://huggingface.co/papers/2608.16798) — 用黑盒 RL 直接训练「Agent 运行框架」本身（而非模型），呼应 harness 作为一等优化目标的趋势。
- [Agentic Transaction: Towards ACID-Compliant Agent Systems](https://huggingface.co/papers/2608.13900) — 清华提出给 Agent 系统套上 ACID 事务语义，让多步工具调用具备原子性 / 回滚，工程化落地关键拼图。

## 【arXiv 精选】

### 论文 / 研究亮点（cs.AI、cs.CL 当日新提交，聚焦 Agent / 工具调用 / 记忆 / 推理控制）

- [AstronOS: A Unified Execution Model and Runtime for Long-Horizon Agentic Systems](https://arxiv.org/abs/2608.16381) — iFLYTEK 提出长程 Agent 的统一执行模型与运行时（23 页 / 13 表），把「执行层」作为一等公民系统化，与 StateM / HarnessEval 形成「harness 工程化」合流。
- [Quipu: A Governed Bitemporal Knowledge Graph Store](https://arxiv.org/abs/2608.16813) — 「严格起步」的受治理双时态知识图谱，专为「Agent 写下的知识」设计默认值，直指 Agent 记忆 / 知识库的治理难题。
- [When Agents Coordinate: Measuring Coordination in Multi-Agent AI Coding](https://arxiv.org/abs/2608.16801) — 量化多 Agent 协作编程中的「协调度」，为多人 / 多 Agent 并行开发的工程实践提供度量。
- [JailbreakSkill: Scaling Automated Red-Teaming with Reusable and Ever-Evolving Skills](https://arxiv.org/abs/2608.16465) — 用可复用、持续演化的「技能」扩展自动化红队，把 skills 范式也用到安全攻防，呼应 skills 工程化。
- [A Policy Algebra for Trust-Preserving Agentic AI Execution](https://arxiv.org/abs/2608.16402) — 用策略代数保证 Agent 执行的「信任保全」，为 Agent 越权 / 失控提供形式化护栏。
- [Governance at the Boundary: How Agent Decomposition Degrades Policy Compliance](https://arxiv.org/abs/2608.16055) — 揭示「把任务拆给多个 Agent」会系统性削弱策略合规，给多 Agent 架构泼了盆冷水（M0 设计需警惕）。
- [HyperSkill: Self-Evolving LLM Agents via Hypergraph-Structured Skill Memory](https://arxiv.org/abs/2608.16114) — 用超图结构技能记忆让 LLM Agent 自我演化，技能 + 记忆双重治理的新范式（cs.CL）。
- [Aborted but Not Forgotten: KV-Cache Retention Breaks Rollback Consistency in Language Agents](https://arxiv.org/abs/2608.15939) — 揭示 KV-cache 保留会破坏语言 Agent 的回滚一致性，与 AgentRewind（昨日）形成「可恢复执行」正反两面（cs.CL）。
